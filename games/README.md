# Games and demonstrations

Application sources and their resources live here. Shared FPGA/GPU drivers,
Linux integration and toolchain support remain outside the games directory.

| Directory | Application |
|---|---|
| [luma](luma/README.md) | Automatic forest adventure and GPU effects finale |
| [orbital](orbital/README.md) | Automatic first-person station tour |
| [astrilla](astrilla/README.md) | Real-time space cinematic, legacy and G3D1 variants |
| [nebula](nebula/README.md) | Linux space shooter |
| [luma3d](luma3d/) | Linux exploration game and minigames; exact MAZE release is published separately |
| [racer](racer/README.md) | Road-racing game in the firmware GPU diagnostic |
| [world3d](world3d/README.md) | Interactive hardware-geometry demonstration |
| [astra](astra/README.md) | Earlier historical space cinematic |
| [luma_adventure](luma_adventure/) | Earlier adventure-engine development branch |
| [common/astrilla](common/astrilla/README.md) | Shared ASTRILLA/WORLD3D scene implementation |

The exact tested MAZE sources and executable are in the immutable
[release package](../releases/luma3d-maze-20261103/README.md). Candidate and
historical test snapshots remain evidence, not alternative maintained copies.
Read the [catalogue](../docs/GAMES.md) for features, controls and limits.
