8 Detailed Design                                                                       8.2 IP Design



                    Figure 8-8 Instruction Memory Configuration




                    ITCM
                         Double-click to open "ITCM", configure the options for ITCM
                    instruction memory, as shown in Figure 8-9.
                         If "ITCM Instruction Memory" is selected, ITCM is enabled as
                    instruction memory, disabled by default.
                        If "ITCM Instruction Memory" is enabled, you can configure the ITCM
                    Size and ITCM Initialization Path.
                       ITCM Size can be configured as 32KB, 64KB, 128KB, 256KB, and
                    512KB, with a default of 64KB.
                         ITCM Initialization Path allows you to configure the initialization path
                    of ITCM, i.e., the executable program for RiscV_AE350_SOC software
                    programming, which is by default the preconfigured LED program under
                    the installation path of Gowin Software. The initialization file of ITCM is in
                    the form of hexadecimal files including itcm0, itcm1, itcm2, and itcm3,
                    which can be generated by using the tool
                    "…\example\Emb_TCM\tool\make_hex".
                          Regarding the application example of ITCM, refer to
                    "...\example\Emb_TCM".
