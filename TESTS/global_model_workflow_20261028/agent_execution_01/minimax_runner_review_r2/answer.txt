## Review

No implementation source, event samples, or isolation-provider implementation were supplied, so this is a contract-level review rather than approval of existing code.

### Evidence from the packet

- `opencode run --format json` exposes `step_start`, `tool_use`, `step_finish`, and `text` events.
- Agent configuration `steps` defines maximum inference rounds.
- `opencode run --session <id>` resumes an exact session.
- OpenCode permissions are approval rules, **not OS isolation**.
- The installed CLI version must be recorded independently.
- The isolation wrapper/model gateway is still being designed; its capabilities cannot be presumed.

### Blocking findings

1. **Security must fail closed.** Until the real provider enforces OS-level filesystem, network, device, and secret restrictions, implementation mode must not start. JSON permission rules receive no security credit. Tool environments must explicitly exclude `OLLAMA_API_KEY`.
2. **Exit 0 is not task completion.** A known task completion requires all of:
   - expected failing baseline observed;
   - agent process exited 0;
   - fresh final tests passed;
   - an independently launched validator reran the pinned tests successfully;
   - changed paths were a subset of the owned-file allowlist;
   - protected inputs were unchanged;
   - isolation evidence remained valid;
   - CLI version was recorded.
   `step_finish` and model text are evidence only, never completion signals.
3. **Use one multi-step initial invocation.** The initial command is one `opencode run --format json` with agent configuration `steps=N`; the controller must not emulate inference steps with an external prompt loop.
4. **Same-session correction has a process-count qualification.** A failed test can be returned to an exited session only through `opencode run --session <same-id>`. Therefore:
   - happy-path demo: one CLI process total;
   - failure path: one initial invocation plus at most two same-session resumes;
   - invocation count must be reported honestly. Exactly one process total and post-exit correction cannot both be guaranteed.
5. **Durability needs write-ahead state and orphan handling.** Persist intent before spawning, append raw events transactionally, commit phase transitions atomically, and mark expired leases `ORPHANED`; never automatically resume an orphan, even when its session ID is known.

## Concrete state machine

Queue state:

```text
QUEUED -> LEASED -> RUNNING -> READY_FOR_MANUAL_REVIEW
                    |             |
                    |             +-> REJECTED
                    +-> CANCELLED
expired lease: RUNNING -> ORPHANED       # no automatic outgoing transition
```

Per-run state:

| Current | Guard | Next |
|---|---|---|
| `QUEUED` | Atomic lease acquired | `LEASED` |
| `LEASED` | Isolated copy, allowlist, protected inputs, and OS controls pass precheck | `COPY_VERIFIED` |
| `COPY_VERIFIED` | Baseline exits nonzero for the exact expected test | `BASELINE_EXPECTED_FAIL` |
| `BASELINE_EXPECTED_FAIL` | Launch initial multi-step agent | `AGENT(0)` |
| `AGENT(i)` | Process terminates normally | `FINAL_GATE(i)` |
| `FINAL_GATE(i)` | Only test failed, exact session known, `i < 2` | `AGENT(i+1)` |
| `AGENT(i+1)` | Resume with the same session ID | `FINAL_GATE(i+1)` |
| `FINAL_GATE(i)` | Fresh test, independent validation, diff, protected-input, security, and version checks all pass | `CANDIDATE_VALIDATED` |
| `CANDIDATE_VALIDATED` | Manifest produced; source remains untouched | `READY_FOR_MANUAL_REVIEW` |
| Any active state | Timeout | `TIMED_OUT` |
| Any active state | Catchable termination signal | `CANCELLED` |
| Any active state | Diff/security/protected-input violation | `REJECTED`, no retry |
| `LEASED`/`RUNNING` | Worker crash and lease expiry | `ORPHANED`, no automatic resume |

The source repository is never an automatic promotion target.

## Python control-flow draft

This is a design draft, not executed code. Production should be split into `state_store.py`, `opencode_adapter.py`, `isolation_adapter.py`, `runner.py`, and `validator.py`, each below 1,000 physical lines.

```python
# controller_draft.py: contract-level design; external adapters are not supplied here.
from dataclasses import dataclass
from pathlib import Path
from typing import Protocol


class Phase:
    QUEUED = "queued"
    LEASED = "leased"
    COPY_VERIFIED = "copy_verified"
    BASELINE_EXPECTED_FAIL = "baseline_expected_fail"
    AGENT = "agent"
    FINAL_GATE = "final_gate"
    CANDIDATE_VALIDATED = "candidate_validated"
    READY_FOR_MANUAL_REVIEW = "ready_for_manual_review"
    REJECTED = "rejected"
    TIMED_OUT = "timed_out"
    CANCELLED = "cancelled"
    ORPHANED = "orphaned"


EDGES = {
    Phase.QUEUED: {Phase.LEASED, Phase.REJECTED},
    Phase.LEASED: {Phase.COPY_VERIFIED, Phase.REJECTED, Phase.CANCELLED,
                   Phase.ORPHANED},
    Phase.COPY_VERIFIED: {Phase.BASELINE_EXPECTED_FAIL, Phase.REJECTED},
    Phase.BASELINE_EXPECTED_FAIL: {Phase.AGENT, Phase.REJECTED},
    Phase.AGENT: {Phase.FINAL_GATE, Phase.TIMED_OUT, Phase.CANCELLED,
                  Phase.REJECTED},
    Phase.FINAL_GATE: {Phase.AGENT, Phase.CANDIDATE_VALIDATED, Phase.REJECTED},
    Phase.CANDIDATE_VALIDATED: {Phase.READY_FOR_MANUAL_REVIEW, Phase.REJECTED},
    Phase.READY_FOR_MANUAL_REVIEW: set(),
    Phase.REJECTED: set(),
    Phase.TIMED_OUT: set(),
    Phase.CANCELLED: set(),
    Phase.ORPHANED: set(),  # Deliberately terminal.
}


@dataclass(frozen=True)
class Limits:
    steps: int
    wall_seconds: int
    max_events: int
    max_tool_calls: int
    continuations: int = 2

    def validate(self) -> None:
        if self.continuations not in range(3):
            raise ValueError("continuations must be 0..2")
        if min(self.steps, self.wall_seconds, self.max_events,
               self.max_tool_calls) <= 0:
            raise ValueError("all limits must be positive")


@dataclass(frozen=True)
class Ticket:
    source: Path
    copy: Path
    owned: tuple[str, ...]
    protected: tuple[str, ...]
    protected_hashes: dict[str, str]
    controls: frozenset[str]
    evidence_digest: str


@dataclass
class ManagedResult:
    exit_code: int | None
    timed_out: bool
    signal: int | None
    session_id: str | None
    failed_tests: tuple[str, ...]
    passed_tests: tuple[str, ...]
    events: tuple[dict, ...]
    stdout_path: Path
    stderr_path: Path


@dataclass
class Gate:
    final_test_exit: int
    validator_test_exit: int
    failed_tests: tuple[str, ...]
    passed_tests: tuple[str, ...]
    changed_paths: tuple[str, ...]
    protected_ok: bool
    isolation_ok: bool
    candidate_digest: str

    def integrity_ok(self, owned: tuple[str, ...]) -> bool:
        return (set(self.changed_paths) <= set(owned)
                and self.protected_ok and self.isolation_ok)

    def ok_for(self, owned: tuple[str, ...],
               expected_tests: tuple[str, ...]) -> bool:
        return (self.final_test_exit == 0
                and self.validator_test_exit == 0
                and not self.failed_tests
                and set(expected_tests) <= set(self.passed_tests)
                and self.integrity_ok(owned))

    def test_only_failure(self, owned: tuple[str, ...]) -> bool:
        return bool(self.failed_tests) and self.integrity_ok(owned)


class Ports(Protocol):
    def prepare_copy(self, spec) -> Ticket: ...
    def run_test(self, copy: Path, command: tuple[str, ...]) -> ManagedResult: ...
    def start_agent(self, copy: Path, agent_config: dict,
                    session_id: str | None, on_event) -> ManagedResult: ...
    def independent_validate(self, copy: Path,
                             pinned_test: tuple[str, ...]) -> Gate: ...
    def cli_version(self) -> str: ...


class Store:
    """SQLite-backed store; each operation is one BEGIN IMMEDIATE transaction."""

    def create(self, task_id: str, run_id: str) -> None: ...
    def claim(self, task_id: str, run_id: str, lease_until: float) -> bool: ...
    def transition(self, run_id: str, expected: str, new: str, **fields) -> None: ...
    def append_event(self, run_id: str, raw: str, parsed: dict) -> int: ...
    def record(self, run_id: str, kind: str, payload: dict) -> None: ...
    def reject(self, run_id: str, reason: str) -> None: ...
    def recover_expired(self, now: float) -> list[str]:
        # Atomically change expired LEASED/RUNNING rows to ORPHANED.
        # This method never calls an agent or validator.
        ...


def precheck(ticket: Ticket) -> None:
    required = {
        "tool_network_denied_by_os",
        "tool_devices_denied_by_os",
        "host_secrets_unavailable",
        "source_read_only",
        "writable_scope_copy_allowlist_only",
        "agent_shell_without_ollama_api_key",
        "model_channel_attested",
    }
    if not required <= ticket.controls or not ticket.evidence_digest:
        raise ValueError("SECURITY_BOUNDARY_UNPROVEN")

    source, copy = ticket.source.resolve(), ticket.copy.resolve()
    if source == copy or copy.is_relative_to(source) or source.is_relative_to(copy):
        raise ValueError("COPY_PRECHECK_FAILED")

    for relative in ticket.owned + ticket.protected:
        rel = Path(relative)
        if rel.is_absolute() or ".." in rel.parts:
            raise ValueError("COPY_PRECHECK_FAILED")
        target = copy / rel
        if target.is_symlink():
            raise ValueError("COPY_PRECHECK_FAILED")
        original = source / rel
        if (original.exists() and target.exists()
                and (original.stat().st_dev, original.stat().st_ino)
                == (target.stat().st_dev, target.stat().st_ino)):
            raise ValueError("COPY_PRECHECK_FAILED")  # Reject hard-link escape.


def correction_proved(before: Gate, after: Gate,
                       result: ManagedResult) -> bool:
    actual_tool_event = any(e.get("type") == "tool_use" for e in result.events)
    failed_now_passing = (bool(before.failed_tests)
                          and set(before.failed_tests) <= set(after.passed_tests))
    artifact_changed = before.candidate_digest != after.candidate_digest
    return actual_tool_event and failed_now_passing and artifact_changed


class Runner:
    def __init__(self, store: Store, ports: Ports, limits: Limits):
        self.store, self.ports, self.limits = store, ports, limits

    def run(self, spec):
        if spec.mode == "review_text":
            return self.legacy_text_review(spec.text)  # Unchanged old path.

        self.limits.validate()
        run_id = spec.new_run_id()
        self.store.create(spec.task_id, run_id)
        if not self.store.claim(spec.task_id, run_id, spec.lease_until):
            raise RuntimeError("QUEUE_CLAIM_FAILED")

        try:
            version = self.ports.cli_version()
            if not version:
                raise ValueError("CLI_VERSION_MISSING")
            self.store.record(run_id, "cli_version", {"version": version})

            ticket = self.ports.prepare_copy(spec)
            precheck(ticket)
            self.store.transition(run_id, Phase.LEASED, Phase.COPY_VERIFIED)

            baseline = self.ports.run_test(ticket.copy, spec.baseline_test)
            if baseline.timed_out or baseline.signal is not None:
                raise ValueError("BASELINE_FAILED")
            if baseline.exit_code == 0:
                raise ValueError("BASELINE_UNEXPECTED_PASS")
            if spec.baseline_failure_id not in baseline.failed_tests:
                raise ValueError("BASELINE_WRONG_FAILURE")
            self.store.record(run_id, "baseline", vars(baseline))
            self.store.transition(run_id, Phase.COPY_VERIFIED,
                                  Phase.BASELINE_EXPECTED_FAIL)

            session_id, before = None, None
            config = {"steps": self.limits.steps, "fingerprint": spec.config_hash}

            # This loops over failed attempts, never over model inference steps.
            for invocation in range(self.limits.continuations + 1):
                expected = (Phase.BASELINE_EXPECTED_FAIL if invocation == 0
                            else Phase.FINAL_GATE)
                self.store.transition(run_id, expected, Phase.AGENT,
                                      invocation=invocation, session_id=session_id)
                result = self.ports.start_agent(
                    ticket.copy, config, session_id,
                    lambda raw: self.store.append_event(run_id, raw, {}))
                self.store.record(run_id, "agent_result", vars(result))

                if result.timed_out:
                    self.store.transition(run_id, Phase.AGENT, Phase.TIMED_OUT)
                    return
                if result.signal is not None:
                    self.store.transition(run_id, Phase.AGENT, Phase.CANCELLED)
                    return
                if not result.session_id:
                    raise ValueError("SESSION_ID_MISSING")
                if session_id and result.session_id != session_id:
                    raise ValueError("SESSION_MISMATCH")
                session_id = result.session_id

                self.store.transition(run_id, Phase.AGENT, Phase.FINAL_GATE,
                                      invocation=invocation)
                gate = self.ports.independent_validate(ticket.copy,
                                                        spec.final_test)
                self.store.record(run_id, "independent_gate", vars(gate))

                if (result.exit_code == 0
                        and gate.ok_for(ticket.owned, spec.expected_final_tests)):
                    if before and not correction_proved(before, gate, result):
                        raise ValueError("CORRECTION_UNPROVED")
                    self.store.transition(run_id, Phase.FINAL_GATE,
                                          Phase.CANDIDATE_VALIDATED)
                    self.store.transition(run_id, Phase.CANDIDATE_VALIDATED,
                                          Phase.READY_FOR_MANUAL_REVIEW)
                    return self.candidate_manifest(run_id)

                if (not gate.test_only_failure(ticket.owned)
                        or invocation >= self.limits.continuations
                        or not session_id):
                    raise ValueError("INVOCATION_BUDGET_EXHAUSTED")
                before = gate
        except ValueError as exc:
            self.store.reject(run_id, str(exc))
            raise
```

The managed-process adapter must start the process in its own containment domain, stream complete JSON lines to the store, preserve an incomplete raw tail, and on timeout or signal terminate the process group with `SIGTERM`, followed by `SIGKILL` after a grace period. A provider-supervisor guarantee is needed if descendants can detach from that group.

## Required metrics

Store raw event JSON and derive only explicitly observed fields:

- `task_id`, `run_id`, `session_id`, and `invocation_index` remain separate.
- `observed_model_step_starts`: count of `step_start` events.
- `observed_model_step_finishes`: count of `step_finish` events.
- `completed_steps`: count of explicitly paired/completed step events; never equated with task completion.
- `api_http_attempts`: `null`/unknown, never inferred from `text`.
- `tool_invocations[]`: one entry per `tool_use`, including step association, name, explicit status, and explicit exit code. Missing fields remain unknown.
- Multiple tool calls in one step count separately.
- `text` is retained as evidence but excluded from completion decisions.
- `opencode_cli_version` comes from separate installation/version capture.

## Five critical test cases

| # | Failure injection | Required assertions |
|---|---|---|
| **1** | **Mode, isolation precheck, and baseline:** first invoke legacy text review. Then separately use implementation mode with: same source/copy path; symlink or hard-link escape; missing OS network/device/secret control; `OLLAMA_API_KEY` present in tool environment; baseline exit 0; baseline failing a different test. Finally provide a valid isolated copy and the expected baseline failure. | Legacy mode returns the unchanged review result and invokes no copy, agent, or test port. Each invalid implementation case reaches `REJECTED` with `COPY_PRECHECK_FAILED`, `SECURITY_BOUNDARY_UNPROVEN`, `BASELINE_UNEXPECTED_PASS`, or `BASELINE_WRONG_FAILURE`, with zero OpenCode calls. The valid case reaches `BASELINE_EXPECTED_FAIL`. Real provider probes must show tool network, device, host-secret, source-write, and protected-write attempts denied by OS controls; owned-copy write remains allowed. |
| **2** | **Exit 0 is insufficient; correction and retry bound:** fake initial invocation emits one step containing two `tool_use` events, a `step_finish`, and misleading text such as “all tests pass,” then exits 0. Independent final test fails `T7`. First resume emits a real `tool_use` and changes the candidate; subsequent fresh tests pass. In a second branch, make all three attempts fail. | Success branch transitions `AGENT(0) → FINAL_GATE(0) → AGENT(1) → FINAL_GATE(1) → CANDIDATE_VALIDATED`. Both invocations use the exact same session and config fingerprint; the initial CLI invocation is configured with multiple steps and is not called once per step. Correction proof contains the actual before/after test outputs, changed candidate digest, and continuation `tool_use` event. Tool count includes both calls in the first step; HTTP attempts remain unknown. Exhaustion branch performs exactly initial + two resumes, reaches `REJECTED(INVOCATION_BUDGET_EXHAUSTED)`, and never invokes a fourth time. |
| **3** | **Integrity violations:** make final tests pass but inject one of: change outside the owned allowlist, modify a protected input, revoke an isolation control, or record a forbidden-access attempt. | Each case reaches `REJECTED` with a specific integrity/security reason, performs no continuation, and cannot produce `CANDIDATE_VALIDATED`. The changed path is reported exactly, protected hashes differ, source remains unchanged, and model text cannot override the result. |
| **4** | **Timeout or signal:** fake agent emits `step_start` and `tool_use`, spawns a child, then hangs. Inject wall timeout in one branch and `SIGTERM`/`SIGINT` in another. | Timeout reaches `TIMED_OUT`; signal reaches `CANCELLED`. The process group and child terminate, no promotion occurs, and partial raw stdout plus parsed events remain durable. The incomplete final JSON line is preserved as a raw tail but not counted as an event. A subsequent run cannot reuse or roll back the partial event history. |
| **5** | **Crash and orphan recovery:** terminate the controller after queue claim, after an event commit, and while a phase transition is in progress. Let the lease expire and reopen the store. | Recovery atomically marks the row `ORPHANED`; it never calls `start_agent`, resumes the old session, or creates a candidate. Committed events and phase remain consistent, with no half-transition. Any manually authorized replacement receives a new `run_id`; it does not silently inherit the orphan’s session or progress. |
