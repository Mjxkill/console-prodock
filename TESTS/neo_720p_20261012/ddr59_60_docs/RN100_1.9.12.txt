                                              1        About This Release

                     The V1.9.12 release includes features and enhancement functions of
                Gowin Software. GOWINSEMI recommends downloading this version to
                get the latest software.
                    The following table summarizes the release items:
                Feature            Description
                Gowin Software: V1.9.12
                                         GW1N-9 Version C
                PN Supported
                                          - GW1N-LV9QN60C6/I5
                                         IP Cores added: Gowin_GoRV32 and
                                          Gowin_GoRV32_Pro were added.
                                         "Add to current project" option added in the "New GPA
                                          Config File" interface.
                                         "SerDes retiming" configuration item added under "Place"
                                          to optimize timing.
                                         Independent PULL MODE settings for P-side and N-side
                                          supported for differential buffers.
                                         DIFF_RESISTOR=ON settings supported for left/right
                                          sides of GW5A(S)(T)-138/GW5A(R)(S)-25 devices.
                                         PWRGRD primitive supported for GW1N-2/GW1N-1P5
                                          devices to enable dynamic GPIO power control and reduce
                                          power consumption.
                New Functions            TLVDS_IOBUF supported for GW1N(R)-2/GW1N(R)-
                                          4/GW1N(R)-9/GW2AN-9X/GW2AN-18X devices.
                                         Physical constraint syntax NET_NO_REP added to
                                          prevent replication of the source DFF of a specified net.
                                         DQS simulation library model of GW5A devices updated to
                                          an encrypted model.
                                         Synthesis attribute syn_dont_touch supported.
                                         Function options added in Programmer: "exFlash Erase
                                          Sectors About File", "exFlash Erase Sectors About File
                                          Arora V", "exFlash Erase Sectors About File thru GAO-
                                          Bridge Arora V", "sFlash Erase Sectors About File",
                                          "sFlash Erase Sectors About File thru GAO-Bridge",
                                          "exFlash Erase Sectors About File thru GAO-Bridge", to
                                          erase the corresponding regions of external Flash based
                                          on the bitstream file size and start address.

                6        Known Problems and Solutions

                    The following problems apply to the supported functions in Gowin
                Software.
                1. If Smart App Control is enabled on Windows 11 system, the software
                   may be blocked, resulting in installation failure.
                     Solution: Disable Smart App Control and then try installing the
                software again.
                2. Failure to generate SSCPLL and SerDes IP on Windows 7 system
                    Solution: Update the Windows operating system to Windows 8 or
                above.
                3. GAO Capture Signal Failure
                    Solution: Try to reduce the number of capture signals and capture
                depth. If the problem still exists, please contact GOWIN support.
                4. GAO PnR Failure
                    ERROR (PR1011): Failed to capture GAO signal<name>,
                because there is no wire to route for the signal.
                     Solution: Check whether the signal is hard-wired, such as the output
                of IOLOGIC.
                5. The information output pane displays messy code on Ubuntu 18.04
                   LTS system
                    The information output pane displays messy code in Linux; when the
                content is copied and pasted to the code editing pane, the display is
                normal.
                      Solution: Delete ide/lib/libfreetype.so.6, and make the software use
                the library that comes with the user's computer system.



RN100-1.9.12E                                                                               8(9)
                                                                  6 Known Problems and Solutions




                6. When simulating vho, the simulator reports an error: Failed to find
                   INSTANCE 'GSR'
                    It is due to the fact that VHDL language does not support the
                duplication of names for primitives and their instantiations.
                     Solution: Modify the instantiation name of the primitive GSR in both
                the vho and .sdf files to "GSR_ins".
                7. For GW1N(R)-9 Version C devices, GowinSynthesis has an
                   inequivalence known issue in inference of asymmetric RAM for
                   SDP.
                    Solution: Add the synthesis attribute synthesis
                syn_ramstyle=registers or synthesis syn_ramstyle=distributed_ram to
                implement asymmetric RAM using logic, though this will increase logic
                resource utilization.
                8. When programming GW5AT-LV138FPG676A, GW5AT-
                   LV138PG676A, GW5AT-LV138PG484A samples, ID Code mismatch
                   is prompted.
                     Solution: When creating a new project, you need to select the
                corresponding GW5AST-138 Version B PN to generate the bitstream file,
                and select the GW5AST-138 Version B device in Programmer.
