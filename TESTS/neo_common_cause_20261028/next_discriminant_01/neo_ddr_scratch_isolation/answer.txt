## R22r1 scratch-isolation audit

**Disposition: NOT PROVEN — stop before any DDR activity.** The supplied evidence does not establish exclusive ownership of `0x12000000..0x1200007f`, nor CPU-write→GPU-read visibility. No hypothesis is treated as proof.

**Audit basis:** candidate SHA-256 `55601256120915adbb08279c0b6bd42caabf8deff261bf87b8a7b8d8cbf9c8aa`; normalized netlist SHA-256 `0eb5638a63c4c2562f78db1dc71474830b7425b23c30b56674639bac4a4cb191`; supplied frozen R19-derived RTL. The current path is `ahb_ddr_cdc`, not the obsolete Sipeed bridge (`ddr_subsys.v:1-6,206-215`). This is a source/packet audit only; no hardware access, execution, or instruction sequence is claimed.

**Footprint:** `0x80` = **128 bytes** = **32 CPU words** = **8 × 16-byte UI beats** = **4 × 32-byte native bursts**. A CPU 4-byte store uses a 32-byte native command footprint, byte-masked to four bytes.
