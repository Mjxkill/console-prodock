## Faits, hypothèses, preuves manquantes

**Faits vérifiables dans le packet**
- Le packet ne numérote pas les lignes. Je cite donc les symboles et extraits exacts de `l3_festival.c` et `l3_festival.h`.
- `positions()`, branche `f->kind==3`, dessine les 7 lanternes avec une alpha **non interpolée** : `i<f->view.data.hangman.mistakes?35:220`.
- `overlay()`, branche `f->kind==3`, dessine encore le mot en texte UI via `ui_text(... word ...)`. C’est ce doublon qu’il faut retirer.
- `textured()` ne connaît que les tuiles 64×64 classiques (`tw=64, columns=8`) et les cartes chroma 32×64 (`tw=32, th=64, columns=16`). Aucun mode « glyphe 32×32 dans l’atlas classique ».
- Les 7 tuiles 57..63 donnent bien **7×4=28 sous-cellules 32×32**, donc 27 glyphes `A..Z+_` tiennent avec une marge.
- `board()` utilise une zone logique 800×400, avec `ww=960`, `hh=480`, `scale=1.2`, centrée. Une pose logique `(400,250)` tombe donc au centre horizontal et entre le hint (`h/2-40`) et l’alphabet (`h*2/3`) pour les deux profils. C’est le bon ancrage pour le mot GPU.
- `L3FestivalPose` contient déjà `chroma`; aucun changement d’en-tête n’est nécessaire.

**Hypothèses à vérifier**
- Les tuiles 57..63 de `festival_classic` sont réellement à zéro après `expand()`.
- `l3_ui_text(dst,32,32,0,0,2,text,78,0)` rend bien chaque glyphe dans 32×32, y compris `_`, sans débordement.
- La couleur de matériau `gpu_material.r/g/b` multiplie bien la texture, permettant un assombrissement du shadow sans nouvelle texture.
- Le filtrage de texture ne fait pas baver les cellules 32×32 adjacentes.

**Preuves manquantes dans le packet**
- Implémentation/prototype exact de `l3_ui_text` et comportement du style 2.
- Sémantique exacte de `gpu_material` et des flags de filtrage.
- Build system, commandes de compilation et harness de test.
- Contenu réel de `f->view.word` (longueur max, espaces, ponctuation).

## Patch minimal proposé

### 1. Rasteriser les glyphes une seule fois, avant publication de l’atlas

À placer avant `art()` :

```c
static void bake_hangman_glyphs(uint16_t *atlas)
{
    static const char glyphs[] = "ABCDEFGHIJKLMNOPQRSTUVWXYZ_";
    _Static_assert(sizeof(glyphs)-1 == 27, "Hangman glyph count");

    for (unsigned g = 0; g < 27; ++g) {
        unsigned tile = 57u + g/4u;
        unsigned cell = g%4u;
        unsigned x = (tile%8u)*64u + (cell%2u)*32u;
        unsigned y = (tile/8u)*64u + (cell/2u)*32u;

        uint16_t cellbuf[32*32];
        memset(cellbuf, 0, sizeof(cellbuf));

        char text[2] = { glyphs[g], 0 };
        l3_ui_text(cellbuf, 32, 32, 0, 0, 2, text, 78, 0);

        for (unsigned row = 0; row < 32; ++row)
            memcpy(atlas + (y+row)*512u + x,
                   cellbuf + row*32u,
                   32u*sizeof(uint16_t));
    }
}
```

Puis dans `art()` remplacer le début :

```c
int ok = expand(work,262144,festival_classic,COUNT(festival_classic));
if(ok) bake_hangman_glyphs(work);
if(ok) publish(r,ATLAS,work,524288);
ok = ok && expand(work,131072,festival_chroma,COUNT(festival_chroma));
if(ok) publish(r,CHROMA,work,262144);
free(work);
```

Aucun upload d’atlas par frame : le seul appel reste dans `art()`, protégé par `if(f->assets)return 1;`.

### 2. Étendre `textured()` pour `chroma==2` et `chroma==3`

Remplacer `textured()` par :

```c
static int textured(L3Render *r,const L3FestivalPose *p,float scale,unsigned alpha)
{
    int tw = 64, th = 64, columns = 8;
    unsigned u, v;
    gpu_texture_level t;

    if (p->chroma == 2 || p->chroma == 3) {
        unsigned g = (unsigned)p->texture;
        if (g >= 27u) return 1; /* glyphe inconnu : ne rien dessiner */

        unsigned tile = 57u + g/4u;
        unsigned cell = g%4u;

        t = (gpu_texture_level){PRODOCK_GPU_BASE+ATLAS,512,512,1024,
                                GPU_ARGB4444,0,0,0};
        u = (tile%8u)*64u + (cell%2u)*32u;
        v = (tile/8u)*64u + (cell/2u)*32u;
        tw = th = 32;
    } else {
        tw = p->chroma ? 32 : 64;
        th = 64;
        columns = p->chroma ? 16 : 8;
        t = (gpu_texture_level){PRODOCK_GPU_BASE+(p->chroma?CHROMA:ATLAS),
                                512,p->chroma?256:512,1024,
                                GPU_ARGB4444,0,0,0};
        u = (p->texture%columns)*tw;
        v = (p->texture/columns)*th;
    }

    gpu_material m = {.flags=1,.alpha=alpha,.r=256,.g=256,.b=256};
    if (p->chroma == 3) {
        /* shadow : même masque, teinte sombre, jamais opaque */
        m.r = 72; m.g = 56; m.b = 32;
    }

    int x = (int)lroundf(p->x*scale);
    int y = (int)lroundf(p->y*scale);
    int w = (int)lroundf(p->w*scale);
    int h = (int)lroundf(p->h*scale);
    if (w < 1 || h < 1) return 1;

    gpu_vertex a[4] = {
        {x,y,u,v,0,65536,256,256,256},
        {x+w,y,u+tw,v,0,65536,256,256,256},
        {x+w,y+h,u+tw,v+th,0,65536,256,256,256},
        {x,y+h,u,v+th,0,65536,256,256,256}
    };

    return gpu_v1_texture(&r->gpu,&t) &&
           gpu_v1_material(&r->gpu,&m) &&
           gpu_v1_quad(&r->gpu,a);
}
```

### 3. Ajouter les poses du mot et lisser les lanternes dans `positions()`

Ajouter avant `positions()` :

```c
static unsigned hangman_glyph(char c)
{
    if (c == '_') return 26u;
    if (c >= 'a' && c <= 'z') c = (char)(c - 'a' + 'A');
    if (c >= 'A' && c <= 'Z') return (unsigned)(c - 'A');
    return 27u; /* espace / ponctuation : pas de pose */
}

static unsigned hangman_old_alpha(const L3Festival *f,int id,
                                  unsigned target,float e)
{
    for (unsigned j = 0; j < f->old_n; ++j) {
        if (f->old[j].id == id) {
            float v = f->old[j].alpha +
                      (target - f->old[j].alpha) * e;
            return (unsigned)lroundf(clamp(v,0.0f,256.0f));
        }
    }
    return target;
}

static void hangman_word(L3Festival *f)
{
    const char *w = f->view.word;
    unsigned n = 0;
    while (w[n] && n < 64u) ++n;
    if (!n) return;

    const float y = 250.0f;      /* au-dessus de l'alphabet, sous le hint */
    const float maxw = 760.0f;
    float step = 36.0f;
    if ((float)n * step > maxw) step = maxw / (float)n;

    float scale = step / 36.0f;
    float gw = 32.0f * scale;
    float gh = 32.0f * scale;
    float start = 400.0f - (float)n * step * 0.5f + step * 0.5f;

    for (unsigned i = 0; i < n; ++i) {
        unsigned g = hangman_glyph(w[i]);
        if (g >= 27u) continue;
        unsigned alpha = (g == 26u) ? 160u : 256u; /* underscore discret */
        pose(f, 2400 + (int)i, (int)g, 2,
             start + (float)i*step - gw*0.5f, y, gw, gh, alpha);
    }
}
```

Remplacer la branche Hangman de `positions()` :


### 4. Fondu des nouvelles lettres et shadow de glyphe dans `board()`

```c
    p->y += (1.0f - e) * 12.0f;
```

## Caveats importants

1. **Débordement de glyphe 32×32**  
   `l3_ui_text` avec style 2 peut écrire jusqu’à 32 px de large. Si un glyphe touche exactement le bord, le filtrage bilinéaire peut baver sur la sous-cellule voisine. À tester ; si artefact, ajouter 1 px transparent autour ou passer le filtrage en nearest.

2. **`_` non rendu par le style 2**  
   Hypothèse non vérifiée. Fallback minimal dans `bake_hangman_glyphs` : si la cellule de `_` est vide, dessiner manuellement une barre de 2 px de haut, couleur 78, entre x=4..27 et y=24..25.

3. **Sémantique de `gpu_material.r/g/b`**  
   Le shadow `m.r=72;m.g=56;m.b=32` suppose une multiplication. Si le matériau ignore ces champs pour les textures ARGB4444, le shadow restera doré. Test visuel nécessaire.

4. **Appuis rapides avant rendu**  
   `act()` copie `f->poses` au moment de l’action. Si deux lettres correctes sont acceptées entre deux rendus, les deux fondus démarrent ensemble depuis le dernier état présenté. La continuité visuelle est conservée, mais pas l’échelonnement par action. Un échelonnement strict exigerait un état par lanterne/lettre, donc un champ d’en-tête — interdit ici.

5. **Cache de page**  
   Les bounds existants ajoutent `+5/+7` ; le shadow ajoute `+2/+3`, donc il reste couvert. Le mot logique reste dans `x=20..780`, `y=250..282`, dans la zone 800×400. À vérifier par test de scissor sur les deux profils.

6. **Chargement/entrée**  
   `l3_festival_enter()` fait `transition=1` et `reset_draw()` remet `old_n=0`. Le mot apparaît donc immédiatement, sans fondu d’entrée. C’est cohérent avec « stable load/entry », mais à valider comme choix UX.
