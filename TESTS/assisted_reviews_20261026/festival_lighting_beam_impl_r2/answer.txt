# Analyse fondée sur le packet

## Faits appuyés
- `games/.../gpu_geometry.c::gpu_geom_set_transform` émet bien **trois** commandes (`GPU_GEOM_MATRIX` pour r=0,1,2), donc 4 instances = 20 commandes si on retransforme à chaque lampe; il faut **un seul restore** de matrice monde puis 4 draws.  
- `games/.../festival.c` contraint `mesh_count` à 24 dans `mesh_flush` (`owner->mesh_count>=24`) et réserve la géométrie à partir de `GEOMETRY=(ATLAS+786432u)` jusqu'à `(18u<<20)`.  
- Le vrai halo existe déjà dans `festival_classic`: atlas 512x512, tuile 56 = `u 0..63`, `v 448..511`; on réutilise donc `(17u<<20)`, sans nouvelle texture/VRAM.  
- Dans la passe 3D, `mat.flags=1|2|4|16` est le mode objet avec Z test et Z write; pour les halos additifs il faut conserver le Z test et supprimer le Z write: `1|2|16|32`.  
- Les faces jardin sont déjà dessinées avec une lumière/ambiance existante; il ne faut pas jouer sur `ambient` du light pour dimuer; l’interpolation se fait via les gains `r,g,b` du matériau.  

## Hypothèses retenues
- `f->map==0` = jour, `f->map==1` = nuit.  
- Le maillage statique actuel laisse assez de place pour **+4 mailles** (un halo par lanterne) sans dépasser 24; le packet indique “17?” comme mesure parentale à valider, et `mesh_flush` garde la borne à l’exécution.  
- Les halos sont traités comme objets géométriques ordinaires pendant la préparation, puis **explicitement ignorés** dans la boucle opaque, pour éviter qu’ils soient dessinés avec le matériau opaque avant l’étape additif.

## Preuves manquantes
- Le nombre exact de mailles actuellement publié n’est pas dans le packet (`?`); la proposition s’appuie sur la garde dure `>=24`.  
- La convention exacte des bits `2` (Ztest) et omission de `4` (no Zwrite) est déduite des appels existants et des corrections fournies; elle n’est pas documentée par un enum nommé dans le packet.  
- L’atmosphère locale précise (position fine du halo sous chaque toit) est proposée, pas mesurée; elle reste bornée et réversible.

## Implémentation: `festival_lighting.c`

```c
#include "festival_lighting.h"

#include <math.h>

static float clampf_range(float v, float a, float b)
{
    if (!isfinite(v)) return a;
    if (v < a) return a;
    if (v > b) return b;
    return v;
}

float festival_lighting_clamp_time(float value)
{
    if (!isfinite(value)) return 0.0f;
    if (value < 0.0f) return 0.0f;
    if (value > 1000.0f) return 1000.0f;
    return value;
}

float festival_lighting_mood_state(const L3Festival *f)
{
    if (!f) return 0.0f;
    return f->map ? 1.0f : 0.0f;
}

float festival_lighting_smooth_mood(float current, float target, float dt)
{
    float rate = festival_lighting_clamp_time(dt) * 1.75f;
    if (rate > 1.0f) rate = 1.0f;
    target = clampf_range(target, 0.0f, 1.0f);
    current = clampf_range(current, 0.0f, 1.0f);
    return current + (target - current) * rate;
}

FestivalLightingLamp festival_lighting_lamp(unsigned lamp_id,
                                            float mood, float time)
{
    FestivalLightingLamp out = {0.0f, 220, 185, 130, 96, 0.0f};
    float t = festival_lighting_clamp_time(time);
    float m = clampf_range(mood, 0.0f, 1.0f);
    unsigned idx = lamp_id & 3u;

    /* Variation lente, continue et desynchronisee entre lanternes. */
    float phase = 0.31f * (float)(idx + 1) + 1.37f * (float)idx;
    float wave = 0.5f + 0.5f * sinf(t * 0.31f + phase);

    /* Interpolation progressive jour -> nuit pour les gains materiau. */
    float base_r = 212.0f + 43.0f * m;
    float base_g = 176.0f + 8.0f * m;
    float base_b = 136.0f - 44.0f * m;

    float amp = 0.88f + 0.12f * wave;
    float r = base_r * amp;
    float g = base_g * amp;
    float b = base_b * amp;

    float energy = (0.35f + 0.65f * m) * (0.88f + 0.12f * wave);
    float alpha = 70.0f + 170.0f * energy;

    out.intensity = clampf_range(energy, 0.0f, 1.0f);
    out.r = (uint16_t)lroundf(clampf_range(r, 0.0f, 256.0f));
    out.g = (uint16_t)lroundf(clampf_range(g, 0.0f, 256.0f));
    out.b = (uint16_t)lroundf(clampf_range(b, 0.0f, 256.0f));
    out.alpha = (uint16_t)lroundf(clampf_range(alpha, 32.0f, 256.0f));
    out.phase = phase + t * 0.31f;
    return out;
}

int festival_lighting_emit_halos(L3Render *r, L3Festival *f,
                                 const gpu_geom_transform *world,
                                 float time)
{
    if (!r || !f || !world) return 0;

    /* Rien a emettre si la geometrie halo n a pas ete publiee. */
    if (!f->lighting_mesh_count ||
        f->lighting_mesh_first + f->lighting_mesh_count > f->mesh_count)
        return 1;

    /* Les coefficients restent calcules hors emission; pas d allocation full ecran. */
    float mood = festival_lighting_mood_state(f);
    (void)time;

    /* Restore de la matrice monde UNE SEULE FOIS : 3 commandes. */
    if (!gpu_geom_set_transform(&r->gpu, world)) return 0;

    /* Reutilisation du vrai atlas, tuile 56 ; 1 commande texture. */
    gpu_texture_level atlas = {(17u << 20), 512u, 512u, 1024u,
                               GPU_ARGB4444, 0, 0, 0};
    if (!gpu_v1_texture(&r->gpu, &atlas)) return 0;

    /* Per-lamp: 4 x (1 materiau + 1 draw) = 8 commandes. Total ajoute : 12. */
    for (unsigned lamp = 0; lamp < 4; ++lamp) {
        FestivalLightingLamp coeff =
            festival_lighting_lamp(lamp, mood,
                                 festival_lighting_clamp_time(f->time));
        gpu_material mat = {.flags = 1u | 2u | 16u | 32u,
                            .alpha = coeff.alpha,
                            .color = 65535u,
                            .r = coeff.r,
                            .g = coeff.g,
                            .b = coeff.b,
                            .fog_near = 0,
                            .fog_color = 0,
                            .fog_scale = 0};

        unsigned mesh_index = f->lighting_mesh_first + lamp;
        if (mesh_index >= 24u || mesh_index >= f->mesh_count) return 0;

        if (!gpu_v1_material(&r->gpu, &mat)) return 0;
        if (!gpu_geom_draw(&r->gpu, &f->meshes[mesh_index], 0)) return 0;

        r->draws++;
        r->triangles += 2;
    }

    return 1;
}
```

### 1. Ajouter `halo_quad` avant `garden_geometry`

```c
static int halo_quad(Mesh *m, L3Vec3 a, L3Vec3 b, L3Vec3 c, L3Vec3 d)
{
    if (m->nv + 6 > 240 || m->nf + 2 > 240)
        if (!mesh_flush(m)) return 0;

    /* 6 sommets independants = max 1024 octets pour 4 halos avec quad3-like. */
    unsigned start = m->nv;
    L3Vec3 points[6] = {a, b, c, a, c, d};
    for (unsigned i = 0; i < 6; ++i) {
        gpu_geom_vertex v = {0};
        if (!gpu_geom_fixed(points[i].x, &v.x) ||
            !gpu_geom_fixed(points[i].y, &v.y) ||
            !gpu_geom_fixed(points[i].z, &v.z))
            return 0;
        m->v[m->nv++] = v;
    }

    for (unsigned tri_index = 0; tri_index < 2; ++tri_index) {
        unsigned s = start + tri_index * 3;
        gpu_geom_face f = {{0}};
        /* UV inset de la tuile 56: u 1..62, v 449..510. */
        uint16_t uu[3] = {1, 62, tri_index ? 1 : 62};
        uint16_t vv[3] = {510, 510, 449};
        f.words[0] = (3u << 24) | s | ((s + 1) << 8) | ((s + 2) << 16);
        f.words[4] = 32767;
        f.words[6] = 256u | (256u << 9) | (256u << 18);
        for (unsigned k = 0; k < 3; ++k)
            f.words[k + 1] = ((uint32_t)uu[k] << 16) | vv[k];
        m->f[m->nf++] = f;
    }
    return 1;
}
```

## Coût et justifications

- **Texture**: aucune nouvelle texture; `halo_tex.base = (17u<<20)` = atlas existant, tuile 56.  
- **Géométrie**: +4 mailles, chacune 6 sommets / 2 faces = +24 sommets et +8 faces. Naïvement: `24*32 + 8*32 = 1024` octets max.  
- **Commandes ajoutées à l’image**:  
  - restore matrice monde : 3  
  - bind atlas : 1  
  - 4 halos x (matériau + draw) : 8  
  - total : **12 commandes ajoutées**, dans le budget ≤16.  
- **Flag exact**: `1|2|16|32` = texture + Ztest + perspective + additif, sans Zwrite.  
- **Transform restoré une seule fois**, donc on évite les 20 commandes d’un `gpu_geom_instance` x4.  
- **Pas de GOURAUD**: aucun `GPU_V1_GOURAUD`, les gains RGB sont interpolés par la fonction pure de coefficients et passés aux 4 appels matériau.  
- **Pas de recomposition CPU plein écran**: seules les commandes GPU supplémentaires sont émises; l’UI native existante n’est pas touchée.  

## Tests de discrimination proposés
1. **Commandes**: compter les commandes entre restore matrice et draw terminal; attendre exactement 12 pour l’éclairage halo.  
2. **UV**: pour chaque face halo, vérifier `u` dans `{1,62}` et `v` dans `{449,510}`; cela prouve la réutilisation de la tuile 56 et non une texture générée.  
3. **Commandes par lampe**: désactiver l’un des 4 halos dans une build instrumentée et vérifier la disparition d’exactement 2 draws/2 tris et 2 commandes.  
4. **Bornes**: obliger `mesh_count` à 24 avant ajout et vérifier que `garden_geometry` échoue proprement grâce à `mesh_flush`, sans écrire hors capacité.  
5. **Coefficients purs**: pour `time` NaN/infini, `festival_lighting_clamp_time` doit renvoyer 0 sans crash; pour `mood` dans `[0,1]`, `r,g,b,alpha` doivent rester dans les bornes GPU.  
6. **Continuité**: faire varier `f->time` par petits pas et vérifier que les gains et alpha ne présentent pas de discontinuité ni de valeur hors clamp.  
7. **Pas de double dessin opaque**: vérifier qu’un halo n’est jamais envoyé par la boucle objet, uniquement par `festival_lighting_emit_halos`, grâce à l’intervalle `lighting_mesh_first..+count`.
