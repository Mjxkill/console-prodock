Hypothèse testable : `l3_simon_native_draw` valide tout avant tout appel `g->emit` (layout, profil, slots page/depth, bornes frame, assets strictement égaux), donc une mutation doit retourner `0` sans incrémenter l’émission. Pour les quatre halos, un frame avec `level_q8[0..3]=256` doit dessiner 12 quads (ombre+halo+clé ×4) dans le scissor `w×h` natif.

Test C discriminant (~33 lignes) :

```c
#include "l3_simon_native_gpu.h"
#include "gpu_v1.h"
#include <assert.h>
#include <string.h>

static unsigned ne;
static void emit(const gpu_command *c){(void)c;ne++;}

static void run(unsigned w,unsigned h){
    L3SimonNativeLayout L; assert(l3_simon_native_layout(w,h,&L));
    L3SimonGpuAssets A; assert(l3_simon_native_assets(&L,&A));
    L3SimonLightFrame F={0}; for(unsigned i=0;i<4;i++){F.level_q8[i]=256;F.radius_q8[i]=128;}
    gpu_v1_context g; memset(&g,0,sizeof g); gpu_v1_init(&g,emit);
    unsigned slot=w==800?1u<<20:2u<<20, base=0x00800000u, depth=base+slot*2, q;
#define FAIL(c) do{ ne=0; assert(!(c)); assert(!ne); }while(0)
    ne=0; assert(l3_simon_native_draw(&g,&L,&A,&F,base,depth,&q)); assert(q==12); assert(ne);
    FAIL(l3_simon_native_draw(&g,&L,&A,&F,base+slot*2,depth,&q)); /* page tierce */
    FAIL(l3_simon_native_draw(&g,&L,&A,&F,base,depth+1,&q));        /* depth invalide */
    {L3SimonGpuAssets B=A;B.background.width=L.w+1;FAIL(l3_simon_native_draw(&g,&L,&B,&F,base,depth,&q));}
    {L3SimonLightFrame E=F;E.level_q8[0]=257;FAIL(l3_simon_native_draw(&g,&L,&A,&E,base,depth,&q));}
    {L3SimonNativeLayout D=L;D.w++;FAIL(l3_simon_native_draw(&g,&D,&A,&F,base,depth,&q));}
    ne=0; assert(l3_simon_native_draw(&g,&L,&A,&F,base+slot,depth,&q)); assert(q==12); assert(ne); /* 4 halos, scissor natif */
}

int main(void){ run(800,480); run(1280,720); puts("PASS"); return 0; }
```

Discrimination : toute régression qui émet avant validation (`FAIL` passera mais `ne` non nul), qui accepte une mutation invalide, ou qui change le nombre de quads avec quatre halos (`!=12`) échoue. Le test ne modifie pas le moteur ; il ne prétend pas exécuter ni produire de trace victoire, seulement un scénario de présentation. Manque d’évidence : layout de `gpu_command` non fourni, donc pas de vérification octet-à-octet des coordonnées/quads contre le scissor ; on suppose `emit` appelé au moins une fois seulement après préflight.
