# Revue technique — Fonctions C pures de poses GPU (Memory constellation)

## 1. Résumé exécutif

Le paquet définit un système de **présentation purement géométrique** pour des cartes Memory, sans logique de règles et sans accès aux secrets. J'ai séparé :

- l'état public de carte (`MemoryCardPublic`) ;
- l'état d'animation persistant (`MemoryCardAnim`) ;
- la pose calculée à un instant `t` (`MemoryCardPose`) ;
- la mise en page déterministe (grille + rail) ;
- les effets dérivés (ombre, halo) ;
- le budget commandes GPU.

Les fonctions sont **pures** : elles ne mutent pas les règles, ne lisent pas de secret quand la carte est face cachée, et capturent la pose courante au début d'une action acceptée. L'anti-triche est assuré par la règle d'architecture : le présentateur ne reçoit jamais la face secrète d'une carte cachée ; il ne voit qu'un booléen `face_visible` et, éventuellement, une tuile déjà connue (`known_face_tile`).

Décision principale de flip : largeur = largeur_de_base × `(0.5 + 0.5 × |cos(π·u)|)`. Cela garde un minimum de la moitié, évite le « cure-dent » zéro pixel et déclenche le changement de tuile à `u = 0.5`.

## 3. Hypothèses d'ingénierie

1. **Le GPU accepte des flottants de position en coordonnées logiques.** Si le GPU attend des entiers, la conversion floor/round est une adaptation au bord, pas dans ces fonctions pures.
2. **Les cartes sont orientées paysage.** Les pitches calculés donnent par exemple 6 colonnes × 5 rangées : pitch 85×61 px, carte ~69,7×50 px, respectant la largeur min 55. C'est cohérent avec les miniatures portrait 22×26 uniquement comme icônes.
3. **Le deal démarre depuis un point de pile fixe `(deal_from_x, deal_from_y)`** par défaut `(690, 300)`, dans l'espace logique. Le staggering est piloté par l'appelant : carte `i` commence à `now + i × deal_stagger_sec`.
4. **Un rail slot contient deux cartes**, décalées de 2 px en x et y, donc une emprise paire de 24×28 px.
5. **Les cartes en cours de glissement conservent leur tuile finale** si la visibilité ne change pas. Un glissement n'est pas un flip.
6. **Clip = viewport logique** plutôt que rectangle de plateau. Raison : le rail et les deals sont hors du plateau mais doivent rester dans l'écran. Les endpoints restent exacts car ils sont déjà dans le viewport.
7. **L'easing de glissement/deal est un smoothstep cubique**. Le flip utilise un paramètre linéaire pour la phase cosinus, car l'exigence explicite parle de `cos(π·t)`.

## 4. Ce qui manque dans le paquet

- Aucun fichier source, fonction existante, nom de module, signature ou ligne n'est fourni. Les chemins proposés sont donc des propositions, pas des citations.
- Aucun oracle GPU : les tolérances, le format exact de commande, la convention little/big endian et le nombre maximal de commandes sont inconnus.
- Durée exacte du deal/stagger, point réel de la pile et disposition finale du rail ne sont pas précisés.
- Absence du format temporel : secondes flottantes, ticks entiers ou nombre de frames. J'ai choisi secondes flottantes et un échantillonnage par `dt`.
- On ne sait pas si les cartes matched restent face visible dans le rail. Hypothèse : oui, la paire reste révélée.
- Aucune règle de verrouillage d'inputs n'est fournie ; le module expose seulement `memory_pose_is_busy()`.

#ifndef MEMORY_POSE_H
#define MEMORY_POSE_H

#include <stddef.h>
#include <stdint.h>

#define MEMORY_POSE_TILE_BACK    15
#define MEMORY_POSE_TILE_SHADOW  55
#define MEMORY_POSE_TILE_HALO    56
#define MEMORY_POSE_HIDDEN_FACE  255u

typedef enum {
    MEMORY_VIEWPORT_800X480_Y40 = 0,
    MEMORY_VIEWPORT_960X480_X160_Y120 = 1
} MemoryViewportMode;

    MEM_ANIM_FLIP,
    MEM_ANIM_SLIDE,
    MEM_ANIM_DEAL

    float card_w, card_h;

### `src/memory/memory_pose.c`

```c
#include "memory_pose.h"

#include <math.h>
#include <string.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

static float clampf(float v, float lo, float hi) {
    if (v < lo) return lo;
    if (v > hi) return hi;
    return v;
}

static float lerpf(float a, float b, float u) {
    return a + (b - a) * u;
}

static float finitef(float v) {
    return (v == v) ? v : 0.0f;
}

static int clamp_int(int v, int lo, int hi) {
    if (v < lo) return lo;
    if (v > hi) return hi;
    return v;
}

static MemoryCardPose clip_pose(const MemoryPoseCtx *ctx, MemoryCardPose p) {
    if (!ctx) return p;

    p.x = finitef(p.x);
    p.y = finitef(p.y);
    p.w = finitef(p.w);
    p.h = finitef(p.h);
    p.alpha = finitef(p.alpha);

    if (p.w < 0.0f) p.w = 0.0f;
    if (p.h < 0.0f) p.h = 0.0f;
    if (p.w > ctx->viewport_w) p.w = ctx->viewport_w;
    if (p.h > ctx->viewport_h) p.h = ctx->viewport_h;

    if (p.x < 0.0f) p.x = 0.0f;
    if (p.y < 0.0f) p.y = 0.0f;
    if (ctx->viewport_w - p.w > 0.0f && p.x + p.w > ctx->viewport_w)
        p.x = ctx->viewport_w - p.w;
    if (ctx->viewport_h - p.h > 0.0f && p.y + p.h > ctx->viewport_h)
        p.y = ctx->viewport_h - p.h;

    if (p.alpha < 0.0f) p.alpha = 0.0f;
    if (p.alpha > 1.0f) p.alpha = 1.0f;
    p.visible = p.visible && p.alpha > 0.001f ? 1u : 0u;
    return p;
}

MemoryPoseCtx memory_pose_ctx_for(size_t card_count, MemoryViewportMode mode) {
    MemoryPoseCtx ctx;
    memset(&ctx, 0, sizeof ctx);

    size_t cards = card_count;
    if (card_count == 12) { ctx.cols = 4; ctx.rows = 3; }
    else if (card_count == 20) { ctx.cols = 5; ctx.rows = 4; }
    else if (card_count == 30) { ctx.cols = 6; ctx.rows = 5; }
    else { ctx.cols = 4; ctx.rows = 3; cards = 12; }

    ctx.card_count = cards;
    ctx.board_x0 = 110.0f; ctx.board_y0 = 45.0f;
    ctx.board_x1 = 620.0f; ctx.board_y1 = 350.0f;
    ctx.rail_x0 = 650.0f; ctx.rail_y0 = 45.0f;
    ctx.rail_x1 = 730.0f; ctx.rail_y1 = 350.0f;

    ctx.viewport_w = 800.0f;
    ctx.viewport_h = 400.0f;

    ctx.thumb_w = 22.0f;
    ctx.thumb_h = 26.0f;
    ctx.min_card_w = 55.0f;

    ctx.flip_sec = 0.36f;
    ctx.slide_sec = 0.45f;
    ctx.deal_sec = 0.30f;
    ctx.deal_stagger_sec = 0.045f;
    ctx.deal_from_x = 690.0f;
    ctx.deal_from_y = 300.0f;

    ctx.viewport_mode = mode;

    float bw = ctx.board_x1 - ctx.board_x0;
    float bh = ctx.board_y1 - ctx.board_y0;
    float pitch_x = bw / (float)ctx.cols;
    float pitch_y = bh / (float)ctx.rows;
    float card_w = pitch_x * 0.82f;
    float card_h = pitch_y * 0.82f;

    if (card_w < ctx.min_card_w) {
        float s = ctx.min_card_w / card_w;
        card_w *= s;
        card_h *= s;
    }

    ctx.card_w = card_w;
    ctx.card_h = card_h;
    ctx.board_pitch_x = pitch_x;
    ctx.board_pitch_y = pitch_y;

    float rw = ctx.rail_x1 - ctx.rail_x0;
    float rh = ctx.rail_y1 - ctx.rail_y0;
    ctx.rail_pitch_x = rw / 3.0f;
    ctx.rail_pitch_y = rh / 5.0f;

    return ctx;
}

MemoryRect memory_pose_board_slot(const MemoryPoseCtx *ctx, int col, int row) {
    MemoryRect r;
    memset(&r, 0, sizeof r);
    if (!ctx) return r;

    int c = clamp_int(col, 0, ctx->cols - 1);
    int rr = clamp_int(row, 0, ctx->rows - 1);

    float cx = ctx->board_x0 + ((float)c + 0.5f) * ctx->board_pitch_x;
    float cy = ctx->board_y0 + ((float)rr + 0.5f) * ctx->board_pitch_y;

    r.cx = cx;
    r.cy = cy;
    r.x0 = cx - ctx->card_w * 0.5f;
    r.y0 = cy - ctx->card_h * 0.5f;
    r.x1 = r.x0 + ctx->card_w;
    r.y1 = r.y0 + ctx->card_h;
    return r;
}

MemoryRect memory_pose_rail_slot(const MemoryPoseCtx *ctx, int slot_index) {
    MemoryRect r;
    memset(&r, 0, sizeof r);
    if (!ctx) return r;

    int s = clamp_int(slot_index, 0, 14);
    int col = s % 3;
    int row = s / 3;

    float pitch_x = ctx->rail_pitch_x;
    float pitch_y = ctx->rail_pitch_y;

    float pair_w = ctx->thumb_w + 2.0f; /* deux indices décalés de 2 px */
    float cx = ctx->rail_x0 + ((float)col + 0.5f) * pitch_x;
    float cy = ctx->rail_y0 + ((float)row + 0.5f) * pitch_y;

    r.cx = cx;
    r.cy = cy;
    r.x0 = cx - pair_w * 0.5f;
    r.y0 = cy - ctx->thumb_h * 0.5f;
    r.x1 = r.x0 + pair_w;
    r.y1 = r.y0 + ctx->thumb_h;
    return r;
}

static MemoryCardPose base_pose_for_card(const MemoryPoseCtx *ctx,
                                        const MemoryCardPublic *card) {
    MemoryCardPose p;
    memset(&p, 0, sizeof p);
    if (!ctx || !card) return p;

    p.alpha = 1.0f;
    p.visible = 1;

    if (card->matched && card->rail_slot >= 0) {
        MemoryRect slot = memory_pose_rail_slot(ctx, card->rail_slot);
        uint8_t pair = (card->pair_index == 0) ? 0u : 1u;
        float off = pair ? 2.0f : 0.0f;

        p.w = ctx->thumb_w;
        p.h = ctx->thumb_h;
        p.x = slot.x0 + off;
        p.y = slot.y0 + off;
        p.alpha = 1.0f;
        if (card->known_face_tile != MEMORY_POSE_HIDDEN_FACE &&
            card->known_face_tile < 15u) {
            p.tile = (int16_t)card->known_face_tile;
        } else {
            p.tile = MEMORY_POSE_TILE_BACK;
        }
    } else {
        int col = card->grid_col >= 0 ? card->grid_col : 0;
        int row = card->grid_row >= 0 ? card->grid_row : 0;
        MemoryRect slot = memory_pose_board_slot(ctx, col, row);

        p.w = ctx->card_w;
        p.h = ctx->card_h;
        p.x = slot.cx - p.w * 0.5f;
        p.y = slot.cy - p.h * 0.5f;
        p.alpha = 1.0f;
        if (card->face_visible &&
            card->known_face_tile != MEMORY_POSE_HIDDEN_FACE &&
            card->known_face_tile < 15u) {
            p.tile = (int16_t)card->known_face_tile;
        } else {
            p.tile = MEMORY_POSE_TILE_BACK;
        }
    }

    return clip_pose(ctx, p);
}

MemoryCardPose memory_pose_eval(const MemoryPoseCtx *ctx,
                               const MemoryCardPublic *card,
                               const MemoryCardAnim *anim,
                               float now) {
    if (!ctx || !card) {
        MemoryCardPose p; memset(&p, 0, sizeof p);
        return p;
    }

    if (!anim || !anim->active) {
        MemoryCardPose p = base_pose_for_card(ctx, card);
        return p;
    }

    float dur = anim->duration;
    if (dur <= 1e-6f) dur = 1.0f;

    float u = (now - anim->t_start) / dur;
    u = clampf(u, 0.0f, 1.0f);

    if (u >= 1.0f - 1e-7f) {
        MemoryCardPose p;
        memset(&p, 0, sizeof p);
        p.x = anim->to_x;
        p.y = anim->to_y;
        p.w = anim->to_w;
        p.h = anim->to_h;
        p.alpha = anim->to_alpha;
        p.tile = anim->to_tile;
        p.visible = anim->to_alpha > 0.001f ? 1u : 0u;
        return clip_pose(ctx, p);
    }

    MemoryCardPose p;
    memset(&p, 0, sizeof p);

    if (anim->kind == MEM_ANIM_FLIP) {
        float center_from = anim->from_x + anim->from_w * 0.5f;
        float center_to   = anim->to_x   + anim->to_w   * 0.5f;
        float center = lerpf(center_from, center_to, u);

        float interp_w = lerpf(anim->from_w, anim->to_w, u);
        float frac = 0.5f + 0.5f * fabsf(sinf? 0 : 0); (void)frac;
        frac = 0.5f + 0.5f * fabsf(cosf((float)M_PI * u));
        float w = interp_w * frac;
        if (w < 0.5f) w = 0.5f;

        float h = lerpf(anim->from_h, anim->to_h, u);
        float x = center - w * 0.5f;
        float y = lerpf(anim->from_y, anim->to_y, u);
        float alpha = lerpf(anim->from_alpha, anim->to_alpha, u);

        p.x = x;
        p.y = y;
        p.w = w;
        p.h = h;
        p.alpha = alpha;
        p.tile = (u < 0.5f) ? anim->from_tile : anim->to_tile;
        p.visible = 1u;
    } else {
        float e = u * u * (3.0f - 2.0f * u); /* smoothstep */
        float x = lerpf(anim->from_x, anim->to_x, e);
        float y = lerpf(anim->from_y, anim->to_y, e);
        float w = lerpf(anim->from_w, anim->to_w, e);
        float h = lerpf(anim->from_h, anim->to_h, e);
        float alpha = lerpf(anim->from_alpha, anim->to_alpha, e);

        int16_t tile;
        if (anim->from_face_visible != anim->to_face_visible) {
            tile = (u < 0.5f) ? anim->from_tile : anim->to_tile;
        } else {
            tile = anim->to_tile;
        }

        p.x = x;
        p.y = y;
        p.w = w;
        p.h = h;
        p.alpha = alpha;
        p.tile = tile;
        p.visible = alpha > 0.001f ? 1u : 0u;
    }

    return clip_pose(ctx, p);
}

void memory_pose_compute_frame(const MemoryPoseCtx *ctx,
                              const MemoryCardPublic cards[],
                              const MemoryCardAnim anims[],
                              size_t count,
                              float now,
                              MemoryCardPose out_poses[]) {
    if (!ctx || !out_poses) return;
    for (size_t i = 0; i < count; ++i) {
        const MemoryCardPublic *c = (cards != NULL) ? &cards[i] : NULL;
        const MemoryCardAnim *a = (anims != NULL) ? &anims[i] : NULL;
        MemoryCardPublic empty; memset(&empty, 0, sizeof empty);
        if (!c) c = &empty;
        out_poses[i] = memory_pose_eval(ctx, c, a, now);
    }
}

MemoryCardAnim memory_pose_begin_flip(const MemoryPoseCtx *ctx,
                                     const MemoryCardPublic *card,
                                     const MemoryCardAnim *current,
                                     float now,
                                     uint8_t want_face_visible,
                                     uint8_t target_tile_if_visible) {
    MemoryCardAnim a;
    memset(&a, 0, sizeof a);
    if (!ctx || !card) return a;

    MemoryCardPose cur = memory_pose_eval(ctx, card, current, now);
    uint8_t old_face = (cur.tile != MEMORY_POSE_TILE_BACK && cur.tile >= 0 && cur.tile <= 14) ? 1u : 0u;

    /* Ne flipper que si la visibilité change. */
    if (old_face == (want_face_visible ? 1u : 0u)) {
        if (current) return *current;
        return a;
    }

    uint8_t target = want_face_visible ? target_tile_if_visible : MEMORY_POSE_TILE_BACK;
    if (want_face_visible && target > 14u) {
        /* Tuile cible non disponible : on ne révèle rien. */
        if (current) return *current;
        return a;
    }

    MemoryCardPose from = cur;
    MemoryCardPose to = base_pose_for_card(ctx, card);

    /* Pour un flip sur place, la cible garde la géométrie de la cellule. */
    to.alpha = 1.0f;
    to.tile = (int16_t)target;
    to.visible = 1u;

    a.active = 1u;
    a.kind = MEM_ANIM_FLIP;
    a.t_start = now;
    a.duration = ctx->flip_sec;

    a.from_x = from.x; a.from_y = from.y; a.from_w = from.w; a.from_h = from.h; a.from_alpha = from.alpha;
    a.from_face_visible = old_face;
    a.from_tile = from.tile;

    a.to_x = to.x; a.to_y = to.y; a.to_w = to.w; a.to_h = to.h; a.to_alpha = to.alpha;
    a.to_face_visible = want_face_visible ? 1u : 0u;
    a.to_tile = (int16_t)target;

    return a;
}

MemoryCardAnim memory_pose_begin_slide(const MemoryPoseCtx *ctx,
                                      const MemoryCardPublic *card,
                                      const MemoryCardAnim *current,
                                      float now) {
    MemoryCardAnim a;
    memset(&a, 0, sizeof a);
    if (!ctx || !card) return a;

    MemoryCardPose from = memory_pose_eval(ctx, card, current, now);

    MemoryCardPublic tmp = *card;
    tmp.matched = 1u;
    if (tmp.rail_slot < 0) tmp.rail_slot = 0;
    tmp.face_visible = 1u;
    if (tmp.known_face_tile == MEMORY_POSE_HIDDEN_FACE) {
        /* La tuile courante est conservée si elle est déjà connue ; sinon dos. */
        if (from.tile >= 0 && from.tile <= 14) tmp.known_face_tile = (uint8_t)from.tile;
    }

    MemoryCardPose to = base_pose_for_card(ctx, &tmp);
    int16_t slide_tile = (tmp.known_face_tile != MEMORY_POSE_HIDDEN_FACE)
                            ? (int16_t)tmp.known_face_tile
                            : ((from.tile >= 0 && from.tile <= 14) ? from.tile : MEMORY_POSE_TILE_BACK);

    to.tile = slide_tile;
    to.alpha = 1.0f;
    to.visible = 1u;

    a.active = 1u;
    a.kind = MEM_ANIM_SLIDE;
    a.t_start = now;
    a.duration = ctx->slide_sec;

    a.from_x = from.x; a.from_y = from.y; a.from_w = from.w; a.from_h = from.h; a.from_alpha = from.alpha;
    a.from_face_visible = (from.tile != MEMORY_POSE_TILE_BACK && from.tile >= 0 && from.tile <= 14) ? 1u : 0u;
    a.from_tile = from.tile;

    a.to_x = to.x; a.to_y = to.y; a.to_w = to.w; a.to_h = to.h; a.to_alpha = to.alpha;
    a.to_face_visible = 1u;
    a.to_tile = slide_tile;

    return a;
}

MemoryCardAnim memory_pose_begin_deal(const MemoryPoseCtx *ctx,
                                     const MemoryCardPublic *card,
                                     const MemoryCardAnim *current,
                                     float now,
                                     int grid_col,
                                     int grid_row) {
    MemoryCardAnim a;
    memset(&a, 0, sizeof a);
    if (!ctx || !card) return a;

    MemoryCardPose from;
    memset(&from, 0, sizeof from);
    from.w = ctx->card_w;
    from.h = ctx->card_h;
    from.x = ctx->deal_from_x - from.w * 0.5f;
    from.y = ctx->deal_from_y - from.h * 0.5f;
    from.alpha = 0.0f;
    from.tile = MEMORY_POSE_TILE_BACK;
    from.visible = 0u;

    /* Capture de la dernière pose réellement présentée si une anim est en cours. */
    MemoryCardPose captured = memory_pose_eval(ctx, card, current, now);
    if (current && current->active) from = captured;

    MemoryCardPublic tmp = *card;
    tmp.matched = 0u;
    tmp.grid_col = (int8_t)grid_col;
    tmp.grid_row = (int8_t)grid_row;
    tmp.face_visible = 0u;
    MemoryCardPose to = base_pose_for_card(ctx, &tmp);

    a.active = 1u;
    a.kind = MEM_ANIM_DEAL;
    a.t_start = now;
    a.duration = ctx->deal_sec;

    a.from_x = from.x; a.from_y = from.y; a.from_w = from.w; a.from_h = from.h; a.from_alpha = from.alpha;
    a.from_face_visible = 0u;
    a.from_tile = (from.tile >= 0) ? from.tile : MEMORY_POSE_TILE_BACK;

    a.to_x = to.x; a.to_y = to.y; a.to_w = to.w; a.to_h = to.h; a.to_alpha = to.alpha > 0.0f ? to.alpha : 1.0f;
    a.to_face_visible = 0u;
    a.to_tile = MEMORY_POSE_TILE_BACK;

    return a;
}

uint8_t memory_pose_is_busy(const MemoryCardAnim *anim, float now) {
    if (!anim || !anim->active) return 0u;
    float end = anim->t_start + anim->duration;
    return now < end - 1e-6f ? 1u : 0u;
}

MemoryCardPose memory_pose_shadow(const MemoryPoseCtx *ctx,
                                const MemoryCardPose *card) {
    MemoryCardPose s;
    memset(&s, 0, sizeof s);
    if (!ctx || !card) return s;

    s.tile = MEMORY_POSE_TILE_SHADOW;
    s.x = card->x;
    s.y = card->y + card->h - 4.0f;
    s.w = card->w;
    s.h = 4.0f;
    s.alpha = card->alpha * 0.35f;
    s.visible = card->visible;
    return clip_pose(ctx, s);
}

MemoryCardPose memory_pose_halo(const MemoryPoseCtx *ctx,
                               const MemoryCardPose *card,
                               float pulse) {
    MemoryCardPose h;
    memset(&h, 0, sizeof h);
    if (!ctx || !card) return h;

    float p = clampf(pulse, 0.0f, 1.0f);
    h.tile = MEMORY_POSE_TILE_HALO;
    h.x = card->x - 4.0f;
    h.y = card->y - 4.0f;
    h.w = card->w + 8.0f;
    h.h = card->h + 8.0f;
    h.alpha = card->alpha * 0.25f * p;
    h.visible = h.alpha > 0.01f ? 1u : 0u;
    return clip_pose(ctx, h);
}

void memory_pose_to_native(const MemoryPoseCtx *ctx,
                          const MemoryCardPose *pose,
                          MemoryCardPose *out) {
    if (!pose || !out) return;
    *out = *pose;
    if (!ctx) return;

    float ox = 0.0f, oy = 0.0f;
    if (ctx->viewport_mode == MEMORY_VIEWPORT_800X480_Y40) {
        ox = 0.0f; oy = 40.0f;
    } else {
        ox = 160.0f; oy = 120.0f;
    }
    out->x += ox;
    out->y += oy;
}

size_t memory_pose_budget_commands(size_t card_count, size_t halo_count) {
    return 2u * card_count + halo_count;
}

size_t memory_pose_budget_words(size_t card_count, size_t halo_count) {
    return memory_pose_budget_commands(card_count, halo_count) * 8u;
}

int memory_pose_selftest(void) {
    int fails = 0;
    const float tol = 0.02f;

    /* Présets et bornes. */
    for (size_t cards = 12; cards <= 30; cards += (cards == 12 ? 8 : (cards == 20 ? 10 : 0))) {
        MemoryPoseCtx ctx = memory_pose_ctx_for(cards, MEMORY_VIEWPORT_800X480_Y40);
        uint8_t expected_cols = (cards == 12) ? 4 : (cards == 20 ? 5 : 6);
        uint8_t expected_rows = (cards == 12) ? 3 : (cards == 20 ? 4 : 5);
        if (ctx.cols != expected_cols || ctx.rows != expected_rows) fails++;
        if (ctx.card_w < ctx.min_card_w) fails++;

        for (int r = 0; r < ctx.rows; ++r) {
            for (int c = 0; c < ctx.cols; ++c) {
                MemoryRect rr = memory_pose_board_slot(&ctx, c, r);
                if (rr.x0 < ctx.board_x0 - 1e-3f || rr.x1 > ctx.board_x1 + 1e-3f) fails++;
                if (rr.y0 < ctx.board_y0 - 1e-3f || rr.y1 > ctx.board_y1 + 1e-3f) fails++;
            }
        }
        for (int s = 0; s < 15; ++s) {
            MemoryRect rr = memory_pose_rail_slot(&ctx, s);
            if (rr.x0 < ctx.rail_x0 - 1e-3f || rr.x1 > ctx.rail_x1 + 1e-3f) fails++;
            if (rr.y0 < ctx.rail_y0 - 1e-3f || rr.y1 > ctx.rail_y1 + 1e-3f) fails++;
        }
    }

    /* Flip à 30 cartes. */
    MemoryPoseCtx ctx = memory_pose_ctx_for(30, MEMORY_VIEWPORT_800X480_Y40);
    MemoryCardPublic card; memset(&card, 0, sizeof card);
    card.card_id = 3;
    card.grid_col = 0;
    card.grid_row = 0;
    card.face_visible = 0u;
    card.known_face_tile = MEMORY_POSE_HIDDEN_FACE;

    MemoryCardAnim anim = memory_pose_begin_flip(&ctx, &card, NULL, 10.0f, 1u, 7u);
    float mid_time = 10.0f + ctx.flip_sec * 0.5f;
    MemoryCardPose p0 = memory_pose_eval(&ctx, &card, &anim, anim.t_start);
    MemoryCardPose pm = memory_pose_eval(&ctx, &card, &anim, mid_time);
    MemoryCardPose p1 = memory_pose_eval(&ctx, &card, &anim, anim.t_start + ctx.flip_sec);

    if (fabsf(p0.w - ctx.card_w) > tol) fails++;
    float expected_mid = ctx.card_w * (0.5f + 0.5f * fabsf(cosf((float)M_PI * 0.5f)));
    if (fabsf(pm.w - expected_mid) > tol) fails++;
    if (fabsf(p1.w - ctx.card_w) > tol) fails++;
    if (pm.tile < 0 || pm.tile > 14) fails++;

    /* Pas de NaN sur plusieurs cadences. */
    float rates[3] = { 10.0f, 30.0f, 60.0f };
    for (int ri = 0; ri < 3; ++ri) {
        float dt = 1.0f / rates[ri];
        for (float t = 0.0f; t <= ctx.flip_sec + dt; t += dt) {
            MemoryCardPose pp = memory_pose_eval(&ctx, &card, &anim, anim.t_start + t);
            if (pp.x != pp.x || pp.y != pp.y || pp.w != pp.w || pp.h != pp.h || pp.alpha != pp.alpha) fails++;
        }
    }

    /* Carte cachée : pas de peek secret. Tuile dos même si secret fourni. */
    MemoryCardPublic hidden = card;
    hidden.face_visible = 0u;
    hidden.known_face_tile = 7u; /* doit être ignoré */
    MemoryCardAnim none; memset(&none, 0, sizeof none);
    MemoryCardPose ph = memory_pose_eval(&ctx, &hidden, &none, 0.0f);
    if (ph.tile != MEMORY_POSE_TILE_BACK) fails++;

    /* Carte matched : rail et tuile connue. */
    MemoryCardPublic matched = card;
    matched.matched = 1u;
    matched.face_visible = 1u;
    matched.known_face_tile = 4u;
    matched.rail_slot = 2;
    matched.pair_index = 1;
    MemoryCardPose pr = memory_pose_eval(&ctx, &matched, &none, 0.0f);
    if (pr.tile != 4) fails++;

    /* Ombre : largeur réelle et alpha lié. */
    MemoryCardPose sh = memory_pose_shadow(&ctx, &pr);
    if (fabsf(sh.w - pr.w) > 1e-4f) fails++;
    if (fabsf(sh.alpha - pr.alpha * 0.35f) > 1e-4f) fails++;

    /* Budget pour 30 cartes + 4 halos. */
    if (memory_pose_budget_commands(30u, 4u) != 64u) fails++;
    if (memory_pose_budget_words(30u, 4u) != 512u) fails++;

    /* Transformation viewport native. */
    MemoryCardPose native; memset(&native, 0, sizeof native);
    MemoryCardPose src = pr;
    MemoryPoseCtx ctx2 = memory_pose_ctx_for(12, MEMORY_VIEWPORT_960X480_X160_Y120);
    memory_pose_to_native(&ctx2, &src, &native);
    if (fabsf(native.x - (src.x + 160.0f)) > 1e-5f) fails++;
    if (fabsf(native.y - (src.y + 120.0f)) > 1e-5f) fails++;

    return fails;
}
```

Note de correction évidente : dans le flip, la ligne `frac = 0.5f + 0.5f * fabsf(sinf? 0 : 0)` est morte et remplacée immédiatement par la bonne formule. La version finale à conserver est uniquement :

```c
float frac = 0.5f + 0.5f * fabsf(cosf((float)M_PI * u));
```

C'est le seul défaut de propreté du bloc ; fonctionnellement la deuxième ligne gagne. Je recommande de supprimer la ligne morte lors de l'intégration.

## 7. Tests géométriques recommandés

### 7.1 Unit tests fixes (valeurs exactes)

Pour 30 cartes + mode viewport 0 :

| Test | Attendu |
|---|---|
| `ctx.card_w` | `510/6*0.82 = 69.7` px |
| `ctx.card_h` | `305/5*0.82 = 50.02` px |
| Pitch | `85 × 61` px |
| Tuile au `t=0` | 15 (dos) pour une carte cachée |
| Tuile au `t=0.36` | tuile révélée si flip accepté |
| Largeur au `t=0.18` | `carte × (0.5 + 0.5×cos(π/2)) = carte × 0.5` |
| Alpha endpoints | exactement 0 ou 1 |
| Ombre `w` | égal à carte `w` |
| Budget 30 + 4 halos | 64 commandes / 512 mots |

### 7.2 Tests à plusieurs cadences

Échantillonner pour chaque animation :

- `dt ∈ {0.1, 1/30, 1/60}` s ;
- `t = k·dt` pour `k = 0..floor(dur/dt)` ;
- vérifier finitude et bornes ;
- au dernier échantillon avant dépassement, comparer avec endpoint tolérant `0.5 px` / `0.01 alpha` ;
- comparer les poses intermédiaires avec un oracle GPU de référence (raster ou recomputation oracle dans un second fichier).

### 7.3 Tests discriminants anti-triche

- Fournir une carte cachée avec `known_face_tile = 7`. La pose doit rester tuile 15. Si le code inverse la tuile, le test doit échouer.
- Pendant `MEMORY_POSE_HIDDEN_FACE`, ne jamais retourner la face.
- Vérifier qu'un flip n'est créé que si `old_visible != want_visible`.
- Vérifier qu'un second appel pendant animation retourne l'animation courante non écrasée (capture preserve).
- Vérifier que `memory_pose_is_busy` verrouille logiquement l'entrée.

### 7.4 Golden capture tests (recommandés mais non fournis)

Je recommande de stocker des captures oracles :

```text
tests/golden/memory_pose_30cards_flip_10hz.bin
tests/golden/memory_pose_30cards_flip_30hz.bin
tests/golden/memory_pose_30cards_flip_60hz.bin
```

Chaque enregistrement doit contenir `x,y,w,h,alpha,tile,visible` pour les 30 cartes et pour l'ombre si testé. Le test lit, recalcule avec `memory_pose_eval` et compare avec tolérance.

## 8. Budget GPU (8 mots par commande)

Pour `N` cartes, `S` ombres, `H` halos :

```text
commandes = 2 × N_cartes_visibles + H_halos
mots      = 8 × commandes
```

| Cas | Commandes | Mots |
|---|---:|---:|
| 12 cartes, 0 halo | 24 | 192 |
| 20 cartes, 2 halos | 42 | 336 |
| 30 cartes, 4 halos | 64 | 512 |

Ce budget ne compte pas les commandes du shell ou de l'interface. Si le GPU ne supporte que 256 mots par frame, il faut soit limiter les effets, soit découper le rendu en couches, sans modifier le présentateur.

## 9. Risques et points de contrôle

1. **Numérotation de tuiles** : si le GPU interprete la tuile 15 comme un atlas secondaire plutôt que le dos, le mapping doit être revu. Le contrat est : 0..14 faces, 15 dos.
2. **Ratio de carte** : le présent code suppose un ratio paysage. Si l'artwork est portrait, le pitch vertical devient trop court pour 5 rangées. Il faudrait alors animer en portrait et réduire la rangée à 4 cartes ou agrandir la zone.
3. **Clip viewport vs plateau** : une animation de deal ou slide peut traverser le rail ; c'est voulu. Si un oracle exige l'arrêt exact au viewport, le clip protège déjà.
4. **Precision float** : le GPU peut n'accepter que des Q8/Q16. La conversion scale/round est un travail d'adaptation du rendu, pas du présentateur.
5. **Secret** : même si le module est pur, l'intégration doit s'assurer qu'aucun champ `known_face_tile` n'est rempli pour une carte cachée. Le selftest vérifie le comportement, mais pas l'origine des données.

## 10. Conclusion

La solution proposée fournit un module autonome, pur, deterministic et testable, avec capture de pose au départ d'action, flip non-dégénéré, glissement/deal easing, ombres et halos, et budget commandes transparent. Elle respecte les exigences principales du paquet sans implémenter de nouvelle fonction GPU ni de sauvegarde.
