Faits: la fonction doit traiter `iterable[bytes]`, sans fichier ; LF, CR seul et CRLF comptent une fin de ligne ; CRLF coupé sur deux morceaux non vide doit être dédupliqué ; fichier vide = 0 ; dernier segment non terminé = 1.

Hypothèses: les morceaux sont `bytes`/`bytearray` indexables ; un morceau vide ne porte pas de données et ne doit pas résoudre prématurément un CR reporté.

```python
def count_physical_lines(chunks):
    t = 0; pending = False; trailing = False
    for chunk in chunks:
        if not chunk:
            continue
        if pending:
            if chunk[:1] == b"\n":
                t += 1; chunk = chunk[1:]
            else:
                t += 1
            pending = False; trailing = False
        i = 0; n = len(chunk)
        while i < n:
            b = chunk[i]
            if b == 10:
                t += 1; trailing = False; i += 1
            elif b == 13:
                if i + 1 < n and chunk[i + 1] == 10:
                    t += 1; trailing = False; i += 2
                elif i + 1 == n:
                    pending = True; trailing = False; i += 1; break
                else:
                    t += 1; trailing = False; i += 1
            else:
                trailing = True; i += 1
    if pending:
        t += 1; trailing = False
    return t + (1 if trailing else 0)
```
