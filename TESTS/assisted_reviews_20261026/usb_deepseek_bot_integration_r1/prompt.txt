2: // (interface stockage de masse, EP1 OUT et EP1 IN). Le protocole Bulk-Only
3: // et SCSI est entièrement dans le firmware ; ce module ne transporte que des

5: //
6: // Fenêtre AHB (0xE9003000) :
7: //   +00 R  identité 0x554d5343 (« UMSC »)
8: //   +04 R  état : bit0 octet reçu disponible, bit1 émission vide (tout octet
9: //          validé a été acquitté par l'hôte), bit2 reset du bus vu,
10: //          bit3 reset Bulk-Only vu, bit4 purge en cours, bit5 configuré,
11: //          bit6 High Speed, bit7 perte (émission ou réception saturée),
12: //          bit8 le firmware sert le disque, bit9 service demandé,
13: //          bit10 garde BOT verrouillé (jusqu'au reset hôte),
14: //          bits 31:16 octets émis non encore acquittés
15: //   +08 R  octet reçu : bit31 = 1 si aucun octet, sinon bits 7:0 et retrait
16: //   +0c W  octet à émettre (bits 7:0)
17: //   +10 W  validation : tous les octets écrits deviennent visibles de l'hôte
18: //   +14 W  commande : bit0 purge des deux sens, bit1 demande à servir le
19: //          disque, bit2 efface « reset du bus », bit3 efface « reset
20: //          Bulk-Only », bit5 rend le disque, bit6 verrouille BOT, bit7 efface « perte »
21: //   +18 R  octets écrits (15:0) et acquittés (31:16), compteurs modulo 65536
22: //   +1c W  quatre octets à émettre, celui des bits 7:0 en premier
23: //   +20 R  quatre octets reçus, le premier dans les bits 7:0, et retrait.
24: //          À ne lire que si +24 en annonce au moins quatre ; sinon la lecture
25: //          rend ce qu'elle a après 15 cycles et lève « perte »

27: //   +28 R  version du contrat BOT : 1 = frontières de paquets + STALL

30: // double horloge, donc dans l'ordre. Côté USB, usb_fifo n'annonce à l'hôte
