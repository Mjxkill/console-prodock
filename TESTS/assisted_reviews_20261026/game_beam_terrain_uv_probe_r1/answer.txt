## Proposition (lecture seule)

**Faits**  
- Le schéma visible est `{"meshes": { "terrain_tx_tz_budget_lodN": {"vertices":..., "faces":[{"indices":[...],"uv":[[u,v],...],...}]}}}`.  
- L’UV attendue est donnée par `((x-tx*32)*255/32, (z-tz*32)*255/32)`.  
- L’export (`export_c.py`) arrondit l’UV en entier 16 bits signé avec `round(v)` (`uv()`), pas en 8.8.  
- Le chemin diagonal NE n’est qu’un symptôme visuel ; il ne prouve pas à lui seul une rupture d’UV.

**Hypothèse à tester**  
- `uv[face][k]` doit être égal à la formule calculée sur `vertices[indices[k]]`.  
- Deux faces partageant une arête `(a,b)` doivent exporter les mêmes UV arrondies aux deux sommets.  
- Les normales et teintes peuvent différer ; on les rapporte sans les corriger.

**Preuves manquantes**  
- Pas de hash/resultat fourni ; le checker doit produire un rapport machine lisible et deux faux négatifs synthétiques.

## Checker Python pur (<=55 lignes)

```python
#!/usr/bin/env python3
import json, re, sys
from pathlib import Path

def check_data(d):
    E = []; nd = 0; colors = set()
    for name, m in d["meshes"].items():
        mm = re.search(r"terrain_(\d+)_(\d+)_budget_lod\d+", name)
        if not mm:
            continue
        tx, tz = int(mm.group(1)), int(mm.group(2))
        V = m["vertices"]; seen = {}
        for fi, f in enumerate(m["faces"]):
            ids, uvs = f["indices"], f["uv"]
            colors.add(tuple(f["color"]))
            for a in range(3):
                vi = ids[a]; x, _, z = V[vi]; u, v = uvs[a]
                want = (round((x - tx*32)*255/32), round((z - tz*32)*255/32))
                if (round(u), round(v)) != want:
                    E.append(f"{name} f{fi} v{vi}: UV {round(u)},{round(v)} != {want[0]},{want[1]}")
            for a in range(3):
                u, v = sorted((ids[a], ids[(a+1) % 3]))
                key = (u, v)
                cur = (
                    (round(uvs[a][0]) if ids[a] == u else round(uvs[(a+1) % 3][0])),
                    (round(uvs[a][1]) if ids[a] == u else round(uvs[(a+1) % 3][1])),
                    (round(uvs[(a+1) % 3][0]) if ids[a] == u else round(uvs[a][0])),
                    (round(uvs[(a+1) % 3][1]) if ids[a] == u else round(uvs[a][1])),
                )
                if key in seen:
                    if seen[key][0] != cur:
                        E.append(f"{name} edge {u}-{v}: UV continuity mismatch")
                    if tuple(seen[key][1]) != tuple(f["normal"]):
                        nd += 1
                else:
                    seen[key] = (cur, list(f["normal"]))
    return {"ok": not E, "errors": E, "normal_edge_differences": nd,
            "tint_values": sorted(colors)}

def check(path):
    return check_data(json.loads(Path(path).read_text()))

def mk():
    V = [[32.0, 0.0, 64.0], [64.0, 0.0, 64.0], [32.0, 0.0, 96.0]]
    return {"meshes": {"terrain_1_2_budget_lod0": {
        "vertices": V, "bounds": {"min": [32, 0, 64], "max": [64, 0, 96]},
        "faces": [{"indices": [0, 1, 2], "normal": [0, 1, 0],
                   "uv": [[0, 0], [255, 0], [0, 255]], "material": 25,
                   "color": [255, 255, 255]}]}}}

def selftest():
    d = mk()
    assert check_data(d)["ok"]
    a = json.loads(json.dumps(d))
    a["meshes"]["terrain_1_2_budget_lod0"]["faces"][0]["uv"][0] = [1, 0]
    assert not check_data(a)["ok"]
    b = json.loads(json.dumps(d))
    f = b["meshes"]["terrain_1_2_budget_lod0"]["faces"][0]
    Vs = b["meshes"]["terrain_1_2_budget_lod0"]["vertices"]
    xs = [Vs[i][0] for i in f["indices"]]; zs = [Vs[i][2] for i in f["indices"]]
    f["uv"] = [[int((x-min(xs))*255/(max(xs)-min(xs))),
                int((z-min(zs))*255/(max(zs)-min(zs)))] for x, z in zip(xs, zs)]
    assert not check_data(b)["ok"]
    print("self-test: 2 synthetic negatives detected")

if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "--self-test":
        selftest()
    else:
        print(json.dumps(check(sys.argv[1]), indent=2))
```

## Usage

```sh
python3 check_uv.py meshes.json
python3 check_uv.py --self-test
```

Sortie : `ok`, `errors`, `normal_edge_differences`, `tint_values`.  
Le script est en lecture seule : il ne modifie ni maillage, ni UV, ni texture. Les deux négatifs synthétiques mutent uniquement des copies en mémoire : une UV changée et une projection volontairement par face, puis vérifient que le checker échoue.

**Conclusion importante** : si le checker passe sur le terrain R6, le défaut visuel chemin diagonal NE n’est pas expliqué par une rupture d’UV ; il faut alors inspecter normales, teintes, éclairage ou LOD. Le code ci-dessus n’a pas été exécuté ici.
