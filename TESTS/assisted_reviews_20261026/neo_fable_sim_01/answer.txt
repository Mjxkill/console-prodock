def sha256(p: Path) -> str:
    h = hashlib.sha256()
    with p.open("rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):

    return h.hexdigest()

    ap.add_argument("--compile-timeout", type=int, default=300)
    ap.add_argument("--sim-timeout", type=int, default=900)
    args = ap.parse_args()

    repo = Path(args.repo).resolve()
    src = (repo / args.source_root).resolve()
    tb = (repo / args.tb).resolve()
    out = Path(args.out).resolve() if args.out else (repo / ALLOWED_OUT / time.strftime("run_%Y%m%d_%H%M%S")).resolve()
    if str(ALLOWED_OUT) not in out.as_posix():
        sys.exit(f"REFUS : sortie {out} hors de {ALLOWED_OUT}")
    out.mkdir(parents=True, exist_ok=False)

    # 1. Gel : les sources doivent etre exactement celles du packet.
    frozen = {}
    for rel, expected in FROZEN.items():
        p = src / rel
        got = sha256(p) if p.exists() else None
        frozen[rel] = {"expected": expected, "actual": got, "ok": got == expected}
    if not all(v["ok"] for v in frozen.values()):
        (out / "result.json").write_text(json.dumps({"passed": False, "reason": "RTL non gele", "frozen": frozen}, indent=2))
        sys.exit("REFUS : SHA256 RTL different du packet R19 : " + json.dumps(frozen, indent=2))

    # 2. Bibliotheques : tout rtl/** en -y (resolution module == nom de fichier), sans copie.
    libdirs = sorted({p.parent for p in (src / "rtl").rglob("*.v")})
    cmd_c = ["iverilog", "-g2012", "-s", TOP, "-o", str(out / "sim.vvp"), "-I", str(src / "rtl"), "-Y", ".v", "-Y", ".sv"]
    for d in args.define:
        cmd_c += ["-D", d]
    for d in libdirs:
        cmd_c += ["-y", str(d)]
    cmd_c += [str(tb)] + [str(src / rel) for rel in FROZEN] + [str((repo / e).resolve()) for e in args.extra]
    # cwd = source-root : le parametre FONT_FILE="rtl/video/font8x16.hex" (S10 l.6) est relatif.
    rc_c, to_c, dt_c = run(cmd_c, src, out / "compile.log", args.compile_timeout)

    result = {
        "tb_sha256": sha256(tb), "launcher_sha256": sha256(Path(__file__).resolve()),
        "frozen": frozen, "reference": REFERENCE, "source_root": str(src),
        "compile": {"cmd": cmd_c, "rc": rc_c, "timeout": to_c, "seconds": round(dt_c, 1)},
        "seed": args.seed, "scenario": args.scenario, "plusargs": args.plusarg, "defines": args.define,

            "Simulation RTL zero-delai : aucune preuve sur routage, LW nets, timing, recovery, PHY DDR.",
            "Terminal DDR modelise (H-MASK, H-LANE) ; ports b_* cables directement (H-PORT).",
            "Ordre des mots de commande suppose word0 en premier (H-WORD).",
        ],
    }
    if rc_c != 0:
        result.update({"passed": False, "reason": "compilation echouee ou expiree"})
        (out / "result.json").write_text(json.dumps(result, indent=2) + "\n")
        sys.exit(2)

    cmd_s = ["vvp", "-N", str(out / "sim.vvp"), f"+seed={args.seed}", f"+scenario={args.scenario}"] + ["+" + p for p in args.plusarg]
    rc_s, to_s, dt_s = run(cmd_s, out, out / "simulation.log", args.sim_timeout)
    log = (out / "simulation.log").read_text(errors="replace")
    verdict = [l for l in log.splitlines() if l.startswith("TB_RESULT")]
    errors = [l for l in log.splitlines() if "TB_ERROR" in l]
    passed = (not to_s) and bool(verdict) and verdict[-1].startswith("TB_RESULT PASS")
    result.update({
        "simulate": {"cmd": cmd_s, "rc": rc_s, "timeout": to_s, "seconds": round(dt_s, 1)},
        "verdict_line": verdict[-1] if verdict else None, "tb_error_count": len(errors),
        "first_errors": errors[:20], "simulation_log_sha256": sha256(out / "simulation.log"),
        "passed": passed,
    })
    (out / "result.json").write_text(json.dumps(result, indent=2) + "\n")
    print(json.dumps({k: result[k] for k in ("passed", "verdict_line", "tb_error_count")}, indent=2))
    sys.exit(0 if passed else 1)

## 3. Chronologie attendue d'un chunk CLEAR 16 px (référence pour `+trace=1`)

| Cycle | gpu_v1 (S12) | gpu_accel (S10) | ddr_gpu_arb (S13) |
|---|---|---|---|
| N | state=RECT_COLOR, native_issue=1 (l.132-135), native_addr/data/mask chargés (l.606) | extended_request=0 | take_blitter=0 |
| N+1 | state=RECT_CSENT, native_valid=1 | v1_request=1, extended_request=1, v1_pending=0 | b_valid=0 |
| N+2 | native_valid=1 | v1_pending=1, v1_tx_* capturés (l.233-236) | b_valid=1, take_blitter=0, b_grant=0 |
| N+3 | native_valid=1 | v1_pending=1 | take_blitter=1, b_grant=1 si m_ready&&m_wr_ready, m_en=m_wr_en=1 |
| N+4 | native_valid=1, ready=1 (RECT_CSENT→RECT_Z) | v1_accepted=1, v1_pending=0, recapture bloquée par !v1_accepted (l.224) | take_blitter=0 |
| N+5 | state=RECT_Z, native_valid=0 | v1_accepted=0, extended_request=0 | idle |

Puis RECT_Z→RECT_NEXT→FINISH (clear_flags=01, span 16 = chunk 16, py+1 ≥ rect_bottom=1). Toute backpressure allonge N+3 seulement : le slot tient le payload et le pixel tient native_valid.

**Point latent révélé par la chronologie :** si à N+4 `fetch_valid` était à 1, `ready` pixel serait masqué (S11 l.60), native_valid resterait à 1 et à N+5 (`v1_accepted` retombé) le slot recapturerait la même requête : doublon d'écriture. Hors scénario CLEAR passthrough, mais C4/C6 le détecteraient.

## 4. Ce que ce banc prouve et ne prouve pas

**Invariants réellement prouvés (si PASS) :** sur le RTL gelé, à délai nul, avec les sources exactes S10-S13 :

- Le FSM pixel, le mux géométrie, le slot `v1_pending/v1_accepted` et l'arbitre produisent exactement une écriture DDR à `0x00200008` avec `{16{5aa5}}` pour la séquence S02, après le FILL legacy `0xa6` au même octet.
- Le payload du slot est stable pendant `v1_pending` et égal à la requête présentée (C3, C4). `native_*` est tenu pendant `native_valid` (C5).
- Aucune acceptation sans requérant, aucune double acceptation, propriétaire unique du port b (C6, C7, C10).
- Progression bornée sous `m_ready` et `m_wr_ready` indépendants et bornés (C8).
- Reset asynchrone avec transaction en attente : pas de commande fantôme, reprise correcte après TARGET. Le variant 2 documente qu'une écriture peut être acceptée au front même du reset.

**Ce qu'il ne dit pas :** rien sur le netlist mappé S18 ni sur le routage. En particulier, `v1_pending` est distribué sur un réseau LW (S15 l.128, S04 global_routes). Son arrivée au cône `b_grant` (S17 `b_grant_s2`), au CE de `v1_tx_write`, et à la logique `n4434` n'est pas qualifiée par la simulation. Le cône `b_grant` lui-même n'est pas dans les quatre preuves S06 : `b_grant` y est une feuille. Les violations de recovery (S04 -0.239 ns vers `u_pixels/u_capture/up_0`, -0.279 ns `engine_resetn_3` vers `u_blitter/st_37`) ne sont pas modélisées. L'IP DDR réelle (polarité du masque, ordre commande/données) n'est pas vérifiée : le FILL legacy la contraint, mais pas la valeur de masque produite par `rect_mask`.

**Valeur discriminante :** un FAIL localise un défaut RTL reproductible et le DUMP donne l'instantané que S03 n'avait pas. Un PASS élimine H1 ci-dessous et concentre la suite sur le mappé/physique.

## 5. Extraits manquants, à fournir plutôt qu'à inventer

- `gpu_accel.v` l.84-178 : déclaration de `ext_active`, `ext_start`, `ext_command`, `done_count`, et la table `hrdata` (offsets de busy/done pour `+status_offset`).
- `gpu_v1.v` l.292-343 : calcul de `rect_mask` et polarité, et TARGET_VALIDATE qui fixe `right/bottom` (sinon RECT_SETUP finit vide, l.594).
- `ddr_subsys.v` l.1-109 : câblage `gpu_accel.valid` vers `blit_valid` (H-PORT).
- Sources de `blitter`, `gpu_raster`, `gpu_copy565`, `gpu_texture_cache`, `ddr_dcfifo` : requises à la compilation, absentes du packet (le lanceur les cherche via `-y rtl/**`).
- Doc IP Gowin DDR3 5.9 : sémantique de `wr_data_mask` et exigence sur `cmd_en` sans `cmd_ready`.
- Confirmation que `v1_select` n'est pas répliqué dans S18 (une réplique divergente serait invisible à S06 qui le traite comme une feuille unique).

## 6. Hypothèses restantes classées

1. **Défaut RTL dans le chemin RECT (rect_mask, right/bottom, v1_select).** Falsifié par un PASS du scénario baseline. Le legacy ne le contraint pas : il n'emprunte ni le slot ni `v1_select` (`valid = legacy_valid || v1_valid`, S10 l.252).
2. **Distribution physique de `v1_pending` (LW) vers l'arbitre ou vers le CE du slot.** Signature attendue : `v1_pending=1` côté accel, `take_blitter` ou `b_grant` jamais vus, ou `v1_accepted` jamais capturé. Falsifié par une capture simultanée de `v1_pending`, `take_blitter`, `b_grant`, `m_ready`, `v1_accepted` au 75 MHz. Le legacy ne le contraint pas : il n'utilise pas `v1_pending`.
3. **Masquage du ready pixel (`fetch_valid` ou copie de `v1_select` à 0 sur le gate S11 l.60).** Signature : `v1_accepted` pulse mais `native_valid` reste à 1 et le slot recapture, ou aucune écriture. Falsifié en capturant `fetch_valid` et `u_pixels.ready` avec `v1_accepted`.
4. **Reset/recovery laissant un registre répliqué incohérent.** Moins probable : l'arrêt est reproductible après power-cycle. Falsifié si l'arrêt dépend de l'ordre de release reset DDR/AHB (`+ddr_init_after_reset=1` en simulation donne la référence attendue).

**Observation matérielle minimale suivante (si le banc PASS) :** huit bits au 75 MHz, déclenchés sur la montée de `u_pixels.native_valid` : `native_valid`, `v1_pending`, `take_blitter`, `b_grant`, `m_ready`, `m_wr_ready`, `v1_accepted`, `u_pixels.ready`. La trace `+trace=1` du banc fournit la séquence attendue cycle par cycle à comparer. Avant tout PnR, étendre `check_handshake_truth.py` (S07) aux cônes `b_grant` et `take_blitter` (S17 `b_grant_s1/s2/s3/s5`, `n500_s0`, `n2632_s2`), ce qui ne demande ni routage ni matériel.
